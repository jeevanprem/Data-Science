Week 01 Introduction to R & Programming Foundations

NPTEL Lectures 01–11 | Course Philosophy, Workspace, Data Structures, Control Flow, and Functions

1. Core Concepts & Systematic Breakdown

R is a high-level interpreted programming language and environment specifically optimized for statistical computing, linear algebra, and data science. Unlike general-purpose languages, R treats vectors as primitive entities, executing calculations natively via SIMD (Single Instruction, Multiple Data) vectorization.

A. Workspace & Environment Architecture

The R interactive session maintains an active workspace in system RAM. Variables, vectors, models, and custom functions exist within the global environment.

  • ls(): Lists names of all active variables and objects residing in the working memory. (Exam trap: it does NOT list filesystem directory contents!)
  • rm(list = ls()): Clears the entire workspace memory.
  • getwd() / setwd(dir): Queries or sets the operating system working directory for relative file I/O.

B. Atomic Data Types & Coercion Hierarchy

R features six primary atomic types: logical, integer (e.g., 10L), numeric (double precision float, e.g., 10.5), complex (e.g., 2 + 3i), character (strings), and raw (bytes). When combining mixed types within an atomic vector, R applies automatic coercive promotion:

Logical $\longrightarrow$ Integer $\longrightarrow$ Numeric (Double) $\longrightarrow$ Character

C. Core Data Structures

  • Vectors: 1-dimensional, strictly homogeneous. Created via c(...) or sequence generators 1:n, seq().
  • Matrices: 2-dimensional, strictly homogeneous. Created using matrix(data, nrow, ncol, byrow = FALSE). By default, R populates matrices column-by-column (byrow = FALSE).
  • Lists: 1-dimensional, heterogeneous recursive containers. Can hold vectors, matrices, nested lists, and data frames simultaneously.
    • list[k]: Returns a sub-list containing the $k$-th element (retains list container).
    • list[[k]]: Extracts the naked content of the $k$-th element.
    • list[[4]][2]: Extracts the 4th element's 2nd internal component.
  • Data Frames: 2-dimensional, heterogeneous tabular structures where each column is a vector of identical length. Access columns via df$column_name or df[["column_name"]].
  • Factors: Categorical variables storing integer codes mapped to string levels.

D. Operators & Control Flow Rules

  • Logical Operators: & and | perform vectorized element-by-element boolean logic. && and || evaluate only the first element (short-circuit scalar evaluation for if statements).
  • Membership Operator: %in% checks if elements of the left vector exist anywhere in the right vector, returning a boolean vector.
  • Matrix Product: %*% computes inner linear algebra matrix multiplication, requiring matching inner dimensions ($m \times k$ with $k \times n$). Standard * computes element-wise Hadamard product!
  • Loop Constructs:
    • for (var in seq) { ... }: Iterates sequentially through each element in a vector.
    • while (condition) { ... }: Repeats code block while condition remains TRUE.
    • repeat { ... if (cond) break }: Executes indefinitely until explicitly terminated via break.
    • next: Skips remainder of current loop iteration and advances counter.
    • break: Terminates the loop structure immediately.

E. String Concatenation & User Input

  • paste() vs paste0():
    • paste(..., sep = " ", collapse = NULL): Joins elements with a default space separator.
    • paste0(...): Fast shortcut for paste(..., sep = "") with zero separation.
    • sep vs collapse (Exam Core): sep is placed between separate argument terms for each corresponding index. collapse collapses the resulting character vector into a single scalar string delimited by the specified token.
  • Console Input & Coercion: readline(prompt = "...") captures input as character data. Numeric computation requires explicit conversion via as.integer() or as.numeric().

F. Reshaping & Merging Data (Lec 6)

  • reshape2 Package:
    • melt(data, id.vars, measure.vars): Wide-to-long transformation.
    • dcast(data, formula, fun.aggregate): Long-to-wide pivot aggregation.
  • merge(x, y, by = ...):
    • Inner Join (all = FALSE): Keeps only matching keys present in both frames.
    • Left Join (all.x = TRUE): Retains all rows from x, filling unmatched y with NA.
    • Full Outer Join (all = TRUE): Retains all rows from both tables.

G. Exploratory Data Inspection & Missing Values

  • str(df): Displays compact structural overview (dimensions, column types, first few observations).
  • summary(df): Computes five-number summary (Min, $Q_1$, Median, Mean, $Q_3$, Max) for numeric features, frequency tables for factors.
  • dim(df), nrow(df), ncol(df): Return row and column dimensions.
  • Missing Data (NA): is.na(x) detects missing values; sum(is.na(df)) counts missing values; na.omit(df) removes incomplete rows.

H. Base Graphics & Visualization (Lec 11)

  • plot(x, y, type = "p", main, xlab, ylab): Creates scatter plots ("p"), line plots ("l"), or both ("b").
  • hist(x, breaks, freq = TRUE): Visualizes continuous frequency distribution (freq = FALSE yields probability density).
  • boxplot(x): Plots median, quartiles, and statistical outliers beyond $1.5 \times \text{IQR}$.
  • barplot(height): Displays bar chart of categorical frequencies.
  • lines(), points(), legend(): Add supplementary layers to an active graphic window.
⚠️

NPTEL Exam Pitfall: Negative Indexing in R vs Python

In Python, a negative index like a[-1] accesses the last element. In R, negative indices mean exclusion / dropping! For instance, A[-2, ] removes the 2nd row and returns a matrix with all remaining rows. Similarly, v[-3] drops the 3rd element.

🎯

Professor's Blueprint: Deconstructing R Nested Subsetting

When evaluating complex nested structures like data$col[condition] <- value or nested_list[[i]][j]:
1. Evaluate innermost bracket first: resolve the index or logical mask.
2. Check container types: Single brackets [ ] preserve the parent class; double brackets [[ ]] extract the underlying element.
3. Pay close attention to logical vector alignment: R recycles short vectors if their length evenly divides the target vector.

2. Mathematical Rules & Vectorization Principles

Vector Recycling Rule Rule
$$\text{length}(v_1) \pmod{\text{length}(v_2)} = 0$$
When operating on two vectors of unequal length, R automatically repeats the shorter vector until it matches the longer vector's length. A warning occurs if not an exact multiple.
Ex 1 If x <- c(1, 2, 3, 4) and y <- c(10, 20), what is x + y?
Sol: Length 4 is an exact multiple of 2 ($4 \pmod 2 = 0$). Vector y recycles to c(10, 20, 10, 20). Result: c(11, 22, 13, 24) (no warning).
Ex 2 What is the output and warning for c(1, 2, 3) + c(1, 2)?
Sol: Length 3 is not a multiple of 2. Shorter vector recycles partially to c(1, 2, 1) producing c(2, 4, 4) with warning: "longer object length is not a multiple of shorter object length".
Matrix Multiplication Dimension Match Linear Algebra
$$A_{(m \times k)} \mathbin{\%*\%} B_{(k \times n)} = C_{(m \times n)}$$
Inner dimensions must match ($k = k$). Element $(i,j)$ is the dot product of row $i$ of $A$ and column $j$ of $B$: $C_{ij} = \sum_{r=1}^k A_{ir} B_{rj}$.
Ex 1 If matrix $A$ is $3 \times 4$ and matrix $B$ is $4 \times 2$, what is the dimension of $A \mathbin{\%*\%} B$?
Sol: Inner dimensions match ($4 = 4$). The resulting product $C$ has dimension $3 \times 2$. Attempting $B \mathbin{\%*\%} A$ throws an error ($2 \ne 3$).
Ex 2 For column vectors $u = [1, 2, 3]^T$ and $v = [4, 5, 6]^T$ ($3 \times 1$), how to get the scalar dot product in R?
Sol: Compute t(u) %*% v which is $(1 \times 3) \times (3 \times 1) = [32]$. In contrast, u * v gives element-wise product c(4, 10, 18).
Negative Subsetting Rule R Syntax
$$A_{[-r, \:]} = \{A_{i, \:} \mid i \in \{1,\dots,m\} \setminus \{r\}\}$$
Negative row or column index deletes that row/column from the returned matrix or data frame.
Ex 1 Given a $4 \times 4$ matrix $M$, what does M[-2, -c(1, 3)] return?
Sol: Deletes row 2 and columns 1 & 3. The returned submatrix has dimension $3 \times 2$ (rows 1, 3, 4 and columns 2, 4).
Ex 2 For vector v <- c(10, 20, 30, 40, 50), what is v[-c(1, 4)]?
Sol: Omits elements at index 1 (10) and index 4 (40). Result: c(20, 30, 50). (Note: R does not allow mixing positive and negative indices).
String Concatenation (sep vs collapse) R Syntax
$$\text{paste}(v_1, v_2, \text{sep}=\sigma), \quad \text{paste}(v, \text{collapse}=\kappa)$$
sep joins corresponding elements across vector arguments; collapse squashes all elements into a single scalar string.
Ex 1 What is paste(c("A","B"), c(1,2), sep="-") vs paste(c("A","B"), collapse="-")?
Sol: With sep = "-", elements are joined pairwise yielding vector c("A-1", "B-2"). With collapse = "-", vector elements are collapsed into scalar "A-B".
Ex 2 What does paste0("Var_", 1:3) return?
Sol: paste0() defaults to zero separator (sep=""). R recycles "Var_" across 1:3 returning c("Var_1", "Var_2", "Var_3").
Boxplot Whiskers & Outlier Rule Graphics & EDA
$$\text{IQR} = Q_3 - Q_1, \quad [Q_1 - 1.5 \times \text{IQR}, \; Q_3 + 1.5 \times \text{IQR}]$$
Whiskers extend to the most extreme data points within $1.5 \times \text{IQR}$. Data points falling beyond the fences are plotted individually as outliers.
Ex 1 If $Q_1 = 20$ and $Q_3 = 35$, compute the upper threshold for outlier detection.
Sol: $\text{IQR} = 35 - 20 = 15$. Upper fence: $Q_3 + 1.5(\text{IQR}) = 35 + 1.5(15) = 57.5$. Any value $> 57.5$ is flagged as an outlier.
Ex 2 For the same dataset, is an observation of $-5$ an outlier?
Sol: Lower fence: $Q_1 - 1.5(\text{IQR}) = 20 - 22.5 = -2.5$. Since $-5 < -2.5$, the observation is an outlier.

Topic: String Manipulation with paste() NPTEL Core Standard

Question 3: What is the distinct role of the parameter collapse in the function paste()?

  • A. It specifies the separator used to join parallel elements across multiple vectors.
  • B. It separates the values of the resulting character vector into a single consolidated string.
  • C. It deletes whitespace from all character elements.
  • D. It folds multi-dimensional arrays into flat vectors.
💡 View Step-by-Step Instructor Solution▼
Step 1: Compare sep vs collapse

In R, paste() takes two delimiter arguments:

  • sep = "...": Defines the delimiter used when concatenating corresponding elements from multiple vectors term-by-term. Returns a vector of length equal to max vector length.

paste(c("X", "Y"), c("1", "2"), sep = "_")
# Output: [1] "X_1" "Y_2" (length 2)

paste(c("X", "Y"), c("1", "2"), sep = "_", collapse = " & ")
# Output: [1] "X_1 & Y_2" (length 1)
✓ Correct Answer: Option B (Separates the values of the resulting character vector into a single consolidated string)

Problem Statement: Data Frame Conditional Mutation & Loop Execution Tracing

An environmental sensor records temperature in three metropolitan regions. A research engineer writes the following R program to update erroneous records and perform automated status logging: 

# Part A: Data Frame Manipulation
name <- c("City A", "City B", "City C")
weather <- c("Sunny", "cloudy", "Rainy")
city_data <- data.frame(name, weather, stringsAsFactors = FALSE)

# Conditional Replacement
city_data$weather[city_data$name == "City C"] <- "Snowy"

# Part B: Algorithmic Loop with 'next' Flow Control
temp_readings <- c(15, 20, 28, 12, 22)
logged_status <- character()

for (temp in temp_readings) {
  if (temp < 18) {
    next # Skip cold days
  }
  if (temp >= 18 && temp <= 25) {
    logged_status <- c(logged_status, "Optimal")
  } else {
    logged_status <- c(logged_status, "High")
  }
}

Answer the following questions:

  1. What is the exact content of the weather column in city_data after the conditional replacement?
  2. What is the length and final contents of the logged_status character vector?
  3. What would happen if the assignment used single brackets & instead of && inside the if conditional?
📘 View Comprehensive Step-by-Step Instructor Solution▼
Solution to Part 1: Data Frame Conditional Modification

The logical condition city_data$name == "City C" generates the logical boolean vector: $$\begin{bmatrix} \text{"City A" == "City C"} \\ \text{"City B" == "City C"} \\ \text{"City C" == "City C"} \end{bmatrix} = \begin{bmatrix} \text{FALSE} \\ \text{FALSE} \\ \text{TRUE} \end{bmatrix}$$ Subsetting city_data$weather[...] selects only the 3rd element, which was initially "Rainy". The assignment <- "Snowy" overwrites row 3. The resulting column is:
Row 1: Sunny, Row 2: cloudy, Row 3: Snowy.

Solution to Part 2: Loop Execution & 'next' Statement Tracing

Tracing through the vector temp_readings <- c(15, 20, 28, 12, 22) step by step:

Iteration temp Value Condition 1: temp < 18 Action Taken logged_status State
1 15 TRUE (15 < 18) next executed: skips iteration character(0)
2 20 FALSE (20 ≥ 18) Matches $18 \le 20 \le 25 \implies$ appends "Optimal" c("Optimal")
3 28 FALSE (28 ≥ 18) Fails $\le 25 \implies$ appends "High" c("Optimal", "High")
4 12 TRUE (12 < 18) next executed: skips iteration c("Optimal", "High")
5 22 FALSE (22 ≥ 18) Matches $18 \le 22 \le 25 \implies$ appends "Optimal" c("Optimal", "High", "Optimal")

The final vector has length 3 and elements: c("Optimal", "High", "Optimal").

Solution to Part 3: Difference Between & and && in Control Flow

In R, the if statement expects a scalar boolean (length 1). When using &&, R performs strict scalar short-circuit evaluation. If single & were used on vector arguments, it would return a logical vector, triggering the warning: "the condition has length > 1 and only the first element will be used". Here temp is scalar, so both yield the same boolean value, but using && is best practice and required standard in R control statements.

✓ Summary: Column 2 becomes [Sunny, cloudy, Snowy]; Logged vector is of length 3: ["Optimal", "High", "Optimal"].

Week 02 Linear Algebra for Data Science

NPTEL Lectures 12–18 | Linear Systems, Rank, Vector Spaces, Span, Norms, Hyperplanes, Eigenvalues & Eigenvectors

1. Core Concepts & Systematic Breakdown

Linear algebra forms the foundational mathematical engine of data science. Datasets are organized as matrices $X \in \mathbb{R}^{n \times p}$ (samples by features), geometric distances govern clustering and nearest neighbors, transformations rely on matrix-vector products, and spectral decomposition (eigenvalues/eigenvectors) underpins Principal Component Analysis (PCA) and dimensionality reduction.

A. Systems of Linear Equations, Rank & Consistency Conditions

Consider the matrix-vector system $Ax = b$, where $A \in \mathbb{R}^{m \times n}$ is the coefficient matrix, $x \in \mathbb{R}^{n \times 1}$ is the unknown variable vector, and $b \in \mathbb{R}^{m \times 1}$ is the target vector. We construct the augmented matrix $[A \mid b] \in \mathbb{R}^{m \times (n+1)}$.

  • Rouché–Capelli Theorem:
    • Inconsistent System (No Solution): $\text{rank}(A) < \text{rank}([A \mid b])$. The target vector $b$ lies outside the column space of $A$.
    • Consistent System: $\text{rank}(A) = \text{rank}([A \mid b])$.
      • Unique Solution: $\text{rank}(A) = \text{rank}([A \mid b]) = n$ (number of variables). The columns of $A$ are linearly independent.
      • Infinitely Many Solutions: $\text{rank}(A) = \text{rank}([A \mid b]) < n$. There exist $n - \text{rank}(A)$ free variables / degrees of freedom.
  • Rank Properties: The maximum number of linearly independent rows or columns. For an $m \times n$ matrix: $\text{rank}(A) \le \min(m, n)$. Furthermore, $\text{rank}(A B) \le \min(\text{rank}(A), \text{rank}(B))$ and $\text{rank}(A^T A) = \text{rank}(A A^T) = \text{rank}(A)$.

B. Overdetermined vs Underdetermined Systems & Pseudoinverses

  • Overdetermined Systems ($m > n$): More equations (measurements) than unknown parameters. Usually inconsistent due to real-world noise.
    • Ordinary Least Squares (OLS) Solution: Minimizes squared residual error $\|Ax - b\|_2^2$. The normal equations are $(A^T A)x = A^T b$.
    • If $A$ has full column rank $n$, $(A^T A)$ is invertible. The unique least-squares solution is: $$\hat{x} = (A^T A)^{-1} A^T b = A^+_{\text{left}} b$$ where $A^+_{\text{left}} = (A^T A)^{-1} A^T$ is the left Moore–Penrose pseudoinverse ($A^+ A = I_n$).
  • Underdetermined Systems ($m < n$): More variables than equations (e.g. genomic data where $p \gg n$). If $\text{rank}(A) = m$, infinitely many exact solutions exist.
    • Minimum-Norm Solution: Finds the solution $x$ satisfying $Ax = b$ with the smallest Euclidean length $\|x\|_2$.
    • Formula using right pseudoinverse: $$\hat{x} = A^T (A A^T)^{-1} b = A^+_{\text{right}} b$$ where $A A^+_{\text{right}} = I_m$.

C. Vector Spaces, Linear Span, and Basis

  • Linear Combination: A vector $v = c_1 v_1 + c_2 v_2 + \dots + c_k v_k$ for scalars $c_i \in \mathbb{R}$.
  • Linear Span: $\text{span}\{v_1, \dots, v_k\}$ is the set of all possible linear combinations.
    Spanning Criterion for $\mathbb{R}^n$: A set of $k$ vectors in $\mathbb{R}^n$ spans $\mathbb{R}^n$ if and only if the matrix formed by taking these vectors as columns has rank equal to $n$. Note: It requires at least $k \ge n$ vectors to span $\mathbb{R}^n$. If $k = n$, this requires $\det([v_1, \dots, v_n]) \ne 0$.
  • Linear Independence: Vectors $\{v_1, \dots, v_k\}$ are linearly independent if $c_1 v_1 + \dots + c_k v_k = 0 \implies c_1 = c_2 = \dots = c_k = 0$. In $\mathbb{R}^n$, any collection of more than $n$ vectors ($k > n$) is guaranteed to be linearly dependent!
  • Basis & Dimension: A basis of a vector space is a linearly independent spanning set. The dimension of $\mathbb{R}^n$ is exactly $n$. Any basis of $\mathbb{R}^n$ must contain precisely $n$ linearly independent vectors.

D. Vector Norms, Angles, Hyperplanes & Halfspaces

  • $L_1$ Norm (Manhattan): $\|x\|_1 = \sum_{i=1}^n |x_i|$. Sum of absolute coordinate distances (used in Lasso regression).
  • $L_2$ Norm (Euclidean): $\|x\|_2 = \sqrt{\sum_{i=1}^n x_i^2} = \sqrt{x^T x}$. Standard geometric distance (used in Ridge regression and KNN).
  • $L_\infty$ Norm (Chebyshev / Max): $\|x\|_\infty = \max_{1 \le i \le n} |x_i|$.
  • Inner Product & Orthogonality: $\langle u, v \rangle = u^T v = \|u\|_2 \|v\|_2 \cos \theta$. Two non-zero vectors are orthogonal ($u \perp v$) if and only if $u^T v = 0$ (i.e. $\cos \theta = 0$).
  • Hyperplanes & Halfspaces: A hyperplane in $\mathbb{R}^n$ is defined as $\mathcal{H} = \{x \in \mathbb{R}^n \mid w^T x + b = 0\}$, where $w$ is the normal vector orthogonal to the plane.
    • Perpendicular Distance from Point $x_0$ to Hyperplane: $$d(x_0, \mathcal{H}) = \frac{|w^T x_0 + b|}{\|w\|_2}$$ • The hyperplane partitions $\mathbb{R}^n$ into two opposing halfspaces: $w^T x + b > 0$ and $w^T x + b < 0$. This is the geometric engine of linear classification and Support Vector Machines (SVM).

E. Spectral Theory: Eigenvalues and Eigenvectors

For a square matrix $A \in \mathbb{R}^{n \times n}$, a non-zero vector $v \ne 0$ is an eigenvector associated with eigenvalue $\lambda$ if: $$A v = \lambda v \iff (A - \lambda I) v = 0$$ For a non-trivial solution ($v \ne 0$) to exist, the matrix $(A - \lambda I)$ must be singular: $$\det(A - \lambda I) = 0 \quad \text{(Characteristic Polynomial)}$$

  • Trace Theorem: $\sum_{i=1}^n \lambda_i = \text{trace}(A) = \sum_{i=1}^n A_{ii}$. (Sum of eigenvalues equals sum of diagonal elements).
  • Determinant Theorem: $\prod_{i=1}^n \lambda_i = \det(A)$. (Product of eigenvalues equals determinant).
  • Matrix Polynomial Shift Theorem: If $A$ has eigenvalues $\lambda_1, \dots, \lambda_n$, then $(A - cI)$ has eigenvalues $(\lambda_1 - c), \dots, (\lambda_n - c)$.
    Consequently: $\det(A - cI) = \prod_{i=1}^n (\lambda_i - c)$.
  • Matrix Inversion: If $A$ is invertible (no zero eigenvalue), $A^{-1}$ has eigenvalues $1/\lambda_i$. Furthermore, $\det(A^{-1}) = \frac{1}{\det(A)}$ and $\det((A^{-1})^T) = \det(A^{-1})$.
  • Scalar Multiplication: For scalar $c$ and $n \times n$ matrix $A$, eigenvalues of $c A$ are $c \lambda_i$, and $\det(c A) = c^n \det(A)$.
  • Symmetric Matrices ($A = A^T$): All eigenvalues are strictly real, and eigenvectors corresponding to distinct eigenvalues are mutually orthogonal.

F. Rank-1 Outer Product Matrices & NPTEL Special Identities

  • Outer Product $M = u u^T$: For non-zero column vector $u = [u_1, \dots, u_n]^T \in \mathbb{R}^n$, the outer product matrix $M = u u^T$ has $\text{rank}(M) = 1$.
    • Notice: $M u = (u u^T) u = u (u^T u) = (\|u\|_2^2) u$. Thus $u$ is an eigenvector with eigenvalue $\lambda_1 = \|u\|_2^2 = \sum_{i=1}^n u_i^2 = \text{trace}(M)$.
    • Since $\text{rank}(M) = 1$, all remaining $n-1$ eigenvalues are exactly zero: $\lambda_2 = \dots = \lambda_n = 0$.
  • Assignment Pattern ($A = [a, b, c]^T$): For matrix $M = A A^T = \begin{bmatrix} a^2 & ab & ac \\ ab & b^2 & bc \\ ac & bc & c^2 \end{bmatrix}$, its eigenvalues are $\lambda_1 = a^2 + b^2 + c^2$, $\lambda_2 = 0$, $\lambda_3 = 0$.
    • Sum of pairwise products: $\lambda_1\lambda_2 + \lambda_2\lambda_3 + \lambda_3\lambda_1 = 0 + 0 + 0 = 0$.
⚠️

NPTEL Exam Pitfall: Inverting Zero Eigenvalues & Matrix Dimensions

Trap 1: The statement "If $\lambda$ is an eigenvalue of $A$, then $1/\lambda$ is always an eigenvalue of $A^{-1}$" is only true if $\det(A) \ne 0$. If $A$ is singular ($\lambda = 0$), $A^{-1}$ does not exist!
Trap 2: To find $\det(A - 2I)$ when given the eigenvalues of $A$, students often attempt to reconstruct matrix $A$. Never do this! Simply subtract 2 from each eigenvalue and multiply: $\det(A - 2I) = (\lambda_1 - 2)(\lambda_2 - 2)\dots(\lambda_n - 2)$.

🎯

Professor's 10-Second Shortcut: Eigenvalues of a 2x2 Matrix

For any $2 \times 2$ matrix $M$, the characteristic polynomial is universally: $$\lambda^2 - \text{trace}(M)\lambda + \det(M) = 0$$ If the problem gives you $\text{trace}(M) = 4$ and $\det(M) = 3$, solve instantly: $$\lambda^2 - 4\lambda + 3 = 0 \implies (\lambda - 1)(\lambda - 3) = 0 \implies \lambda_1 = 1, \; \lambda_2 = 3.$$ No matrix expansion required!

2. Mathematical Formulas & Spectral Identities

Linear System Consistency Rouché-Capelli
$$\text{rank}(A) = \text{rank}([A \mid b])$$
System $Ax = b$ is consistent iff augmented matrix rank equals coefficient matrix rank. Unique if rank $= n$; infinite if rank $< n$.
Ex 1 A system of 3 variables has $\text{rank}(A) = 2$ and $\text{rank}([A \mid b]) = 3$. How many solutions exist?
Sol: Since $\text{rank}(A) \ne \text{rank}([A \mid b])$, the system is inconsistent. There are $0$ solutions (no solution).
Ex 2 If $\text{rank}(A) = \text{rank}([A \mid b]) = 2$ for $n = 3$ variables, what is the nature of solutions?
Sol: Ranks match, so system is consistent. Because $\text{rank} < n$, there are infinitely many solutions parameterized by $n - \text{rank} = 3 - 2 = 1$ free variable.
Eigenvalue Trace & Det Identities Spectral
$$\sum_{i=1}^n \lambda_i = \text{tr}(A), \quad \prod_{i=1}^n \lambda_i = \det(A)$$
Sum of eigenvalues equals the matrix trace (sum of diagonal entries). Product of eigenvalues equals the matrix determinant.
Ex 1 A $3 \times 3$ matrix $A$ has $\text{tr}(A) = 9$, $\det(A) = 24$, and known eigenvalues $\lambda_1 = 2, \lambda_2 = 3$. Find $\lambda_3$.
Sol: Trace property: $2 + 3 + \lambda_3 = 9 \implies \lambda_3 = 4$. Verification via determinant: $2 \times 3 \times 4 = 24$.
Ex 2 A $2 \times 2$ matrix has trace $5$ and determinant $6$. What are its eigenvalues?
Sol: Characteristic equation is $\lambda^2 - 5\lambda + 6 = 0 \implies (\lambda - 2)(\lambda - 3) = 0 \implies \lambda_1 = 2, \; \lambda_2 = 3$.
Determinant of Shifted Matrix Spectral Theorem
$$\det(A - cI) = \prod_{i=1}^n (\lambda_i - c)$$
The determinant of $(A - cI)$ is simply the product of each eigenvalue shifted by constant $c$.
Ex 1 Matrix $A$ has eigenvalues $4$ and $7$. What is $\det(A - 3I)$?
Sol: Shift each eigenvalue by $3$: $(\lambda_1 - 3)(\lambda_2 - 3) = (4 - 3)(7 - 3) = 1 \times 4 = 4$.
Ex 2 If matrix $M$ has eigenvalues $-1, 2, 5$, what is $\det(M + 2I)$?
Sol: $M + 2I = M - (-2)I$, so shift eigenvalues by $+2$: $(-1 + 2)(2 + 2)(5 + 2) = 1 \times 4 \times 7 = 28$.
Orthogonality Condition Geometry
$$u^T v = \sum_{i=1}^n u_i v_i = 0$$
Two non-zero vectors $u$ and $v$ are orthogonal if and only if their Euclidean inner product vanishes.
Ex 1 For what value of $k$ are $u = [1, k, 3]^T$ and $v = [4, -2, 2]^T$ orthogonal?
Sol: Set $u^T v = 0 \implies (1)(4) + (k)(-2) + (3)(2) = 0 \implies 4 - 2k + 6 = 0 \implies 2k = 10 \implies k = 5$.
Ex 2 Are columns $q_1 = [3/5, 4/5]^T$ and $q_2 = [-4/5, 3/5]^T$ orthonormal?
Sol: Dot product $(3/5)(-4/5) + (4/5)(3/5) = 0$ (orthogonal). Lengths $\|q_1\| = \sqrt{9/25+16/25} = 1$, $\|q_2\| = 1$. Yes, orthonormal.
Point-to-Hyperplane Distance Geometry
$$d(x_0, \mathcal{H}) = \frac{|w^T x_0 + b|}{\|w\|_2}$$
Perpendicular Euclidean distance from point $x_0$ to hyperplane $w^T x + b = 0$. Sign of $w^T x_0 + b$ indicates the halfspace.
Ex 1 Find distance from $x_0 = [1, 2]^T$ to line $3x_1 + 4x_2 - 6 = 0$.
Sol: Normal vector $w = [3, 4]^T$, so $\|w\|_2 = \sqrt{3^2 + 4^2} = 5$. Numerator: $|3(1) + 4(2) - 6| = |5| = 5$. Thus $d = 5/5 = 1$.
Ex 2 Do points $[0, 0]^T$ and $[2, 1]^T$ lie in the same halfspace of $2x_1 - x_2 + 4 = 0$?
Sol: At origin: $2(0) - (0) + 4 = +4 > 0$. At $[2, 1]^T$: $2(2) - 1 + 4 = +7 > 0$. Both yield positive signs, so yes, they lie in the same halfspace.
Moore-Penrose Pseudoinverses Least Squares
$$A^+_{\text{left}} = (A^T A)^{-1} A^T, \quad A^+_{\text{right}} = A^T (A A^T)^{-1}$$
Left pseudoinverse solves overdetermined OLS $\min \|Ax-b\|^2$; right pseudoinverse finds minimum-norm solution for underdetermined systems.
Ex 1 Given overdetermined system $x = 2$ and $2x = 3$, find the least squares estimate $\hat{x}$.
Sol: Matrix $A = [1, 2]^T$, $b = [2, 3]^T$. $A^T A = 1^2 + 2^2 = 5$, and $A^T b = 1(2) + 2(3) = 8$. Thus $\hat{x} = (A^T A)^{-1} A^T b = 8/5 = 1.6$.
Ex 2 When does $(A^T A)^{-1}$ exist for an $m \times n$ matrix with $m > n$?
Sol: $(A^T A)$ of size $n \times n$ is non-singular and invertible if and only if $A$ has full column rank $n$ (linearly independent columns).
Rank-1 Outer Product Eigenvalues Spectral Theorem
$$M = u u^T \implies \lambda_1 = \|u\|_2^2, \quad \lambda_2 = \dots = \lambda_n = 0$$
The outer product of vector $u \in \mathbb{R}^n$ with itself has rank 1. Its only non-zero eigenvalue is $\|u\|^2 = \text{tr}(M)$. All other $n-1$ eigenvalues equal 0.
Ex 1 Find all eigenvalues of $M = u u^T$ for $u = [1, 2, 2]^T$.
Sol: $\lambda_1 = 1^2 + 2^2 + 2^2 = 9$. Because $\text{rank}(M) = 1$, the other two eigenvalues are $\lambda_2 = 0, \lambda_3 = 0$.
Ex 2 For $M = A A^T$ where $A = [a, b, c]^T$, what is the sum of pairwise products $\sum_{i < j} \lambda_i \lambda_j$?
Sol: Eigenvalues are $(a^2+b^2+c^2, 0, 0)$. Each pair includes at least one zero eigenvalue, so $\lambda_1\lambda_2 + \lambda_2\lambda_3 + \lambda_3\lambda_1 = 0$.

Question 1: Does the set $S = \{(1, 1), (1, 2)\}$ span $\mathbb{R}^2$?

  • B. No

Method 1: First-Principles Linear Combination Test

To span $\mathbb{R}^2$, any arbitrary vector $(x, y) \in \mathbb{R}^2$ must be expressible as: $$a(1, 1) + b(1, 2) = (x, y)$$ Equating components: $$a + b = x \quad \text{and} \quad a + 2b = y$$ Subtracting the first equation from the second: $$b = y - x$$ Substituting back into $a + b = x$: $$a = x - b = x - (y - x) = 2x - y$$ Since unique real scalars $a = 2x - y$ and $b = y - x$ exist for every $(x, y) \in \mathbb{R}^2$, the set $S$ spans $\mathbb{R}^2$.

Week 03 Probability, Random Variables & Hypothesis Testing

NPTEL Lectures 19–22 | Probability Spaces, Discrete & Continuous Distributions, Expectation, CLT, and Hypothesis Testing

1. Core Concepts & Systematic Breakdown

Data is inherently subject to noise, measurement uncertainty, and random variability. Probability provides the rigorous mathematical calculus to model uncertainty, while statistical inference allows engineers to deduce population characteristics from finite empirical samples.

A. Measures of Central Tendency & Data Types

  • Mean (Arithmetic Average): $\bar{X} = \frac{1}{n}\sum x_i$. Appropriate for continuous, symmetrically distributed data without severe outliers. Sensitive to extreme values.
  • Median (50th Percentile): Middle value of sorted observations. Robust to outliers and extreme skewness (preferred for income, house prices). Appropriate for ordinal and continuous data.
  • Mode (Most Frequent Value): The single most frequent observation or category.
    • CRITICAL NPTEL EXAM RULE: Mode is the ONLY measure of central tendency that can be computed for categorical / nominal data! (e.g. eye color, car brand, machine brand). You cannot compute the mean or median of categorical labels.

B. Probability Axioms, Bayes' Theorem & Sampling Schemes

  • Multiplication Rule & Conditional Probability: $$P(A \cap B) = P(A \mid B) P(B) = P(B \mid A) P(A)$$ If $A$ and $B$ are independent, $P(A \cap B) = P(A) P(B)$ and $P(A \mid B) = P(A)$.
  • Law of Total Probability & Bayes' Rule: If events $B_1, B_2, \dots, B_k$ partition the sample space: $$P(A) = \sum_{j=1}^k P(A \mid B_j) P(B_j)$$ $$P(B_i \mid A) = \frac{P(A \mid B_i) P(B_i)}{\sum_{j=1}^k P(A \mid B_j) P(B_j)}$$ Classic NPTEL Problem: Factory receives components from Supplier 1 ($60\%$, $2\%$ defective) and Supplier 2 ($40\%$, $5\%$ defective). If a randomly chosen item is defective, the probability it came from Supplier 1 is: $$P(S_1 \mid D) = \frac{0.02 \times 0.60}{(0.02 \times 0.60) + (0.05 \times 0.40)} = \frac{0.012}{0.012 + 0.020} = \frac{0.012}{0.032} = 0.375 \; (37.5\%)$$
  • Sampling With vs Without Replacement:
    • With Replacement: Trials are independent; constant probability of success $\implies$ Binomial Distribution $B(n, p)$.
    • Without Replacement: Trials are dependent; finite population of size $N$ with $K$ successes $\implies$ Hypergeometric Distribution: $$P(X = k) = \frac{\binom{K}{k} \binom{N - K}{n - k}}{\binom{N}{n}}$$

C. Mathematical Expectation, Variance, and Scaling Rules

  • Expected Value $E[X]$: Discrete: $E[X] = \sum_i x_i P(X = x_i)$. Continuous: $E[X] = \int_{-\infty}^{\infty} x f(x) dx$.
    Linearity: $E[aX + bY + c] = aE[X] + bE[Y] + c$ (holds universally, even if dependent!).
  • Variance $\text{Var}(X)$: Measures dispersion: $\text{Var}(X) = E[X^2] - (E[X])^2$.
    • $\text{Var}(aX + c) = a^2 \text{Var}(X)$ (constants have zero variance; scalars square!).
    • Independent variables: $\text{Var}(aX + bY) = a^2 \text{Var}(X) + b^2 \text{Var}(Y)$.
    • $$\mathbf{\text{Var}(aX - bY) = a^2 \text{Var}(X) + b^2 \text{Var}(Y)} \quad \text{(CRUCIAL: Variances NEVER subtract!)}$$
  • Covariance & Pearson Correlation: $\text{Cov}(X, Y) = E[XY] - \mu_X \mu_Y$.
    Correlation: $\rho_{XY} = \frac{\text{Cov}(X, Y)}{\sigma_X \sigma_Y} \in [-1, 1]$. Standardized, dimensionless, scale-invariant.

D. Sample Statistics & Sampling Distributions

  • Sample Mean: $\bar{X} = \frac{1}{n}\sum X_i$, $E[\bar{X}] = \mu$, $\text{SE}(\bar{X}) = \frac{\sigma}{\sqrt{n}}$.
  • Central Limit Theorem (CLT): For iid samples with mean $\mu$ and finite $\sigma^2$, as $n \ge 30$, $\frac{\bar{X} - \mu}{\sigma / \sqrt{n}} \xrightarrow{d} N(0, 1)$, regardless of population shape.
  • Sample Variance ($s^2$): $s^2 = \frac{1}{n-1}\sum (X_i - \bar{X})^2$. Unbiased because of Bessel's correction ($n-1$).
  • Sampling Distribution of Sample Variance (Chi-Square): If a random sample $X_1, \dots, X_n$ is drawn from a normal population $N(\mu, \sigma^2)$, the quantity: $$\frac{(n - 1) s^2}{\sigma^2} \sim \chi^2_{n - 1}$$ follows a Chi-Square distribution with $n - 1$ degrees of freedom. Expected value is $E[\chi^2_{n-1}] = n - 1$, and variance is $2(n - 1)$.

E. Hypothesis Testing Framework & Decision Rules

  • Null ($H_0$) & Alternative ($H_a$): $H_0: \mu = \mu_0$ vs $H_a: \mu \ne \mu_0$ (two-tailed) or $H_a: \mu > \mu_0$ (one-tailed).
  • Errors: Type I Error ($\alpha$) = Rejecting true $H_0$ (significance level). Type II Error ($\beta$) = Failing to reject false $H_0$. Power $= 1 - \beta$.
  • Decision Rule: $\text{Reject } H_0 \iff p\text{-value} < \alpha$.
  • One-Sample Z-Test: (Known $\sigma$) $Z = \frac{\bar{X} - \mu_0}{\sigma / \sqrt{n}} \sim N(0, 1)$. Reject if $|Z| > 1.96$ for $\alpha = 0.05$.

F. Two-Sample & Paired $t$-Tests

  • Independent Two-Sample $t$-Test: Compares means of two distinct groups (e.g. Group A vs Group B). $$t = \frac{\bar{X}_1 - \bar{X}_2}{s_p \sqrt{\frac{1}{n_1} + \frac{1}{n_2}}}, \quad s_p^2 = \frac{(n_1 - 1)s_1^2 + (n_2 - 1)s_2^2}{n_1 + n_2 - 2}, \quad \text{df} = n_1 + n_2 - 2$$
  • Paired $t$-Test (Repeated Measures): Used when observations are matched pairs on the SAME subjects (e.g., patient blood pressure Before vs After treatment).
    • Computes differences $d_i = X_{\text{after}, i} - X_{\text{before}, i}$.
    • Reduces to a one-sample $t$-test on difference variable $d$: $$t = \frac{\bar{d} - 0}{s_d / \sqrt{n}}, \quad \text{df} = n - 1$$
⚠️

NPTEL Exam Pitfall: Variance of Difference vs Sum

A classic trap in Week 3 assignments: If $X$ and $Y$ are independent, what is $\text{Var}(4X - 2Y + 5)$?
$$\text{Var}(4X - 2Y + 5) = 4^2 \text{Var}(X) + (-2)^2 \text{Var}(Y) + 0 = 16\text{Var}(X) + 4\text{Var}(Y)$$ Common Error: Students write $16\text{Var}(X) - 4\text{Var}(Y)$. Variances NEVER subtract! Squaring $(-2)^2$ yields $+4$. Constant $+5$ has zero variance.

Professor's Z-Test 30-Second Execution Blueprint

1. Identify given values: Sample mean $\bar{X}$, Null mean $\mu_0$, Population standard deviation $\sigma$, Sample size $n$.
2. Calculate Standard Error: $\text{SE} = \sigma / \sqrt{n}$.
3. Calculate Test Statistic: $Z = (\bar{X} - \mu_0) / \text{SE}$.
4. Compare with critical value ($1.96$ for $5\%$ two-tailed) or compute $p = 2(1 - \Phi(|Z|))$.
5. Conclude: If $|Z| > 1.96$ or $p < 0.05$, reject $H_0$!

2. Essential Mathematical Formulas & Test Statistics

Variance of Linear Combination Probability
$$\text{Var}(aX \pm bY) = a^2\text{Var}(X) + b^2\text{Var}(Y) \pm 2ab\text{Cov}(X,Y)$$
For independent variables, $\text{Cov}(X,Y) = 0$, so $\text{Var}(aX - bY) = a^2\text{Var}(X) + b^2\text{Var}(Y)$.
Ex 1 If independent $X, Y$ have $\text{Var}(X) = 4, \text{Var}(Y) = 9$, what is $\text{Var}(3X - 2Y + 7)$?
Sol: Constants shift location without affecting spread: $\text{Var}(3X - 2Y + 7) = 3^2(4) + (-2)^2(9) + 0 = 36 + 36 = 72$. (Note: negative coefficient squared becomes $+4$).
Ex 2 If $\text{Cov}(X, Y) = 2, \text{Var}(X) = 5, \text{Var}(Y) = 3$, find $\text{Var}(2X + Y)$.
Sol: $\text{Var}(2X + Y) = 2^2(5) + 1^2(3) + 2(2)(1)(2) = 20 + 3 + 8 = 31$.
One-Sample Z-Statistic Inference
$$Z = \frac{\bar{X} - \mu_0}{\sigma / \sqrt{n}} \sim N(0, 1)$$
Standardizes difference between observed sample mean $\bar{X}$ and hypothesized mean $\mu_0$ under known population standard deviation $\sigma$.
Ex 1 Given $n = 36, \bar{X} = 52, \mu_0 = 50, \sigma = 6$, calculate $Z$ and state decision at $\alpha = 0.05$.
Sol: $\text{SE} = 6/\sqrt{36} = 1.0$. $Z = (52 - 50)/1.0 = 2.00$. Since $|Z| = 2.00 > 1.96$, reject $H_0$.
Ex 2 How does $Z$ change if sample size is quadrupled ($4n$) for fixed $(\bar{X} - \mu_0)$?
Sol: $\text{SE} \propto 1/\sqrt{n}$. Quadrupling $n$ halves the denominator ($1/\sqrt{4} = 1/2$), which exactly doubles the test statistic $Z$.
Sample Variance (Unbiased) Bessel
$$s^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2$$
Divisor $n-1$ accounts for loss of 1 degree of freedom from estimating the population mean via $\bar{X}$.
Ex 1 Compute sample variance $s^2$ for sample $\{2, 4, 6, 8, 10\}$ ($n = 5$).
Sol: $\bar{X} = 6$. Squared deviations: $(2-6)^2=16, (4-6)^2=4, 0, 4, 16$ (sum = $40$). Bessel's divisor $n-1 = 4$: $s^2 = 40/4 = 10$.
Ex 2 Why does R's var() divide by $n-1$ instead of $n$?
Sol: Dividing by $n$ produces a biased underestimate ($E[s_n^2] = \frac{n-1}{n}\sigma^2$). The $n-1$ divisor ensures an unbiased estimator ($E[s^2] = \sigma^2$).
Pearson Correlation Coefficient Association
$$\rho_{XY} = \frac{\text{Cov}(X, Y)}{\sigma_X \sigma_Y} \in [-1, 1]$$
Measures linear association strength and direction. Scale-invariant and dimensionless.
Ex 1 If $\text{Cov}(X, Y) = 15, s_X = 5, s_Y = 6$, find $r_{XY}$ and the SLR $R^2$.
Sol: $r_{XY} = 15 / (5 \times 6) = 0.50$. In simple linear regression, $R^2 = r_{XY}^2 = (0.50)^2 = 0.25$ (25% variance explained).
Ex 2 If $Y = -3X + 7$, what is $\text{cor}(X, Y)$?
Sol: Perfect linear inverse relationship with negative slope ($-3 < 0$) yields $\text{cor}(X, Y) = -1.00$.
Bayes' Rule with Total Probability Inference
$$P(B_1 \mid A) = \frac{P(A \mid B_1) P(B_1)}{P(A \mid B_1) P(B_1) + P(A \mid B_2) P(B_2)}$$
Inverts conditional probability: updates prior belief $P(B_1)$ into posterior belief $P(B_1 \mid A)$ upon observing evidence $A$.
Ex 1 Machine 1 makes 70% of parts (1% defect); Machine 2 makes 30% (4% defect). If a part is defective, find $P(M_1 \mid D)$.
Sol: $P(M_1 \mid D) = \frac{0.01 \times 0.70}{(0.01)(0.70) + (0.04)(0.30)} = \frac{0.007}{0.007 + 0.012} = \frac{0.007}{0.019} \approx 0.3684$ (36.84%).
Ex 2 State the Law of Total Probability for a 2-event partition $\{B, B^c\}$.
Sol: $P(A) = P(A \mid B)P(B) + P(A \mid B^c)P(B^c)$. Total probability decomposes $A$ into mutually exclusive disjoint components.
Sampling Distribution of Sample Variance Chi-Square
$$\frac{(n - 1) s^2}{\sigma^2} \sim \chi^2_{n - 1}$$
Scaled sample variance of normally distributed data follows a Chi-Square distribution with $n-1$ degrees of freedom.
Ex 1 For a normal sample with $n = 16$, what is the expected value of $\frac{(n-1)s^2}{\sigma^2}$?
Sol: Degrees of freedom $\nu = n - 1 = 15$. For any $\chi^2_\nu$ distribution, $E[\chi^2_\nu] = \nu$. Thus expected value is $15$.
Ex 2 What is the variance of the statistic $\frac{(n-1)s^2}{\sigma^2}$?
Sol: $\text{Var}(\chi^2_\nu) = 2\nu = 2(n - 1)$. For $n = 16$, variance $= 2(15) = 30$.
Hypergeometric Sampling (Without Replacement) Combinatorics
$$P(X = k) = \frac{\binom{K}{k} \binom{N - K}{n - k}}{\binom{N}{n}}$$
Probability of $k$ successes in $n$ dependent draws from finite population size $N$ containing $K$ total successes without replacement.
Ex 1 A lot of 10 items has 3 defectives. If 2 items are drawn without replacement, find $P(X = 2)$.
Sol: $P(X = 2) = \frac{\binom{3}{2}\binom{7}{0}}{\binom{10}{2}} = \frac{3 \times 1}{45} = \frac{1}{15} \approx 0.0667$.
Ex 2 How does this contrast with sampling with replacement?
Sol: With replacement, draws are independent: $P(X = 2) = (3/10) \times (3/10) = 0.090$ (governed by Binomial distribution $B(n=2, p=0.3)$).

Null Hypothesis: $H_0: \mu = 4.0$ (The true mean tensile strength is $4.0$).

Week 04 Optimization Foundations: Univariate Methods

NPTEL Lectures 23–26 | Problem Formulation, Local vs Global Extrema, FONC/SOSC, Convexity, and Iterative Search

1. Core Concepts & Systematic Breakdown

Machine learning and data science can be unified as applied optimization problems. Whether finding best-fit linear regression parameters by minimizing squared errors, maximizing classification likelihoods, or minimizing cluster variances, optimization provides the mathematical engine.

A. Mathematical Optimization Problem Formulation

A mathematical optimization model is formally defined by three elements: $$\min_{x \in \Omega} f(x) \quad \text{or} \quad \max_{x \in \Omega} f(x)$$ where $f(x): \mathbb{R} \to \mathbb{R}$ is the objective function, $x$ is the decision variable, and $\Omega \subseteq \mathbb{R}$ is the feasible region bounded by operational equality ($h_i(x) = 0$) and inequality ($g_j(x) \le 0$) constraints.

  • Optimization Duality (Sign Inversion): Maximizing $f(x)$ is mathematically identical to minimizing $-f(x)$: $$\max_{x \in \Omega} f(x) \iff \min_{x \in \Omega} [-f(x)]$$
  • Global vs Local Extrema:
    • $x^*$ is a global minimum if $f(x^*) \le f(x)$ for all $x \in \Omega$.
    • $x^*$ is a local minimum if $f(x^*) \le f(x)$ in an $\epsilon$-neighborhood around $x^*$.
  • Extreme Value Theorem (Weierstrass): If $f(x)$ is continuous on a closed and bounded interval $[a, b]$, $f(x)$ is guaranteed to attain both an absolute maximum and an absolute minimum on $[a, b]$.
    • CRITICAL SOLVING PROCEDURE: Evaluate $f(x)$ at:
        1. All interior stationary points $x_i \in (a, b)$ where $f'(x_i) = 0$.
        2. All points where $f'(x)$ fails to exist.
        3. The interval boundary endpoints $x = a$ and $x = b$!
    The largest of these candidate values is the global maximum; the smallest is the global minimum.

B. Analytical Optimality Conditions (FONC & SOSC)

For a continuous, twice-differentiable univariate function $f(x)$ on an open domain:

  • First-Order Necessary Condition (FONC):
    If $x^*$ is an interior local extremum, the first derivative must vanish: $$\mathbf{f'(x^*) = 0}$$ Points where $f'(x^*) = 0$ are called stationary points.
  • Second-Order Necessary Condition (SONC):
    • If $x^*$ is a local minimum $\implies f''(x^*) \ge 0$.
    • If $x^*$ is a local maximum $\implies f''(x^*) \le 0$.
  • Second-Order Sufficient Condition (SOSC):
    Let $x^*$ be a stationary point ($f'(x^*) = 0$):
    • $\mathbf{f''(x^*) > 0} \implies x^*$ is a strict local minimum (curving upward).
    • $\mathbf{f''(x^*) < 0} \implies x^*$ is a strict local maximum (curving downward).
    • $\mathbf{f''(x^*) = 0} \implies$ Inconclusive (test higher derivatives).
  • Higher-Order Derivative Rule (Inflection Points): If the first non-vanishing derivative at a stationary point is of odd order $k$ (e.g. $f'''(x^*) \ne 0$), then $x^*$ is an inflection point (neither min nor max, e.g. $f(x) = x^3$ at $0$). If of even order $k$, it is a min if $f^{(k)}(x^*) > 0$ and max if $f^{(k)}(x^*) < 0$ (e.g. $f(x) = x^4$ at $0$).

C. Convexity and Uniqueness of Optima

  • Convex Function: A function $f(x)$ is convex if $f''(x) \ge 0$ everywhere on the interval.
    Fundamental Convexity Theorem: For a convex function, any local minimum is unconditionally a global minimum! If $f''(x) > 0$ strictly, the global minimum is unique.
  • Concave Function: $f''(x) \le 0$ everywhere. Any local maximum is a global maximum.

D. Numerical Univariate Search Methods (Bracketing & Interpolation)

  • Bisection Method (Derivative-Based): Used to solve $f'(x) = 0$ inside bracketing interval $[a, b]$ where $f'(a) f'(b) < 0$.
    • At each iteration, evaluates midpoint $m = (a + b)/2$ and discards half the interval.
    • Interval width after $k$ steps: $\Delta_k = \frac{b - a}{2^k}$.
    • Linear convergence with error reduction factor $1/2$. Guaranteed convergence, though slow.
  • Golden Section Search (Derivative-Free): Finds minimum of unimodal $f(x)$ on $[a, b]$ without computing derivatives.
    • Maintains constant golden ratio $\tau = \frac{\sqrt{5} - 1}{2} \approx 0.618$. Discards $1 - \tau \approx 0.382$ of the interval each step.
  • Secant Method: Replaces the exact second derivative $f''(x_k)$ in Newton's method with a finite difference slope between two successive points $x_k, x_{k-1}$: $$x_{k+1} = x_k - f'(x_k) \frac{x_k - x_{k-1}}{f'(x_k) - f'(x_{k-1})}$$ Exhibits superlinear convergence (order $\approx 1.618$) without requiring $f''(x)$.

E. Gradient Descent & Newton–Raphson

  • Gradient Descent (1D): Steps opposite to the local slope: $$x_{k+1} = x_k - \alpha f'(x_k)$$ where $\alpha > 0$ is the learning rate (step size). If $\alpha$ is too small, convergence is sluggish; if $\alpha$ is too large, it overshoots and diverges.
  • Newton–Raphson Method for Optimization: Minimizes local 2nd-order Taylor expansion: $$x_{k+1} = x_k - \frac{f'(x_k)}{f''(x_k)}$$ Exhibits quadratic convergence ($|e_{k+1}| \propto |e_k|^2$) near the optimum. Requires $f''(x_k) > 0$.
⚠️

NPTEL Exam Pitfall: Root-Finding vs Optimization in Newton-Raphson

Common Blunder: Students frequently mix up the two distinct forms of Newton-Raphson:
1. Finding roots of $g(x) = 0$: $x_{k+1} = x_k - \frac{g(x_k)}{g'(x_k)}$.
2. Minimizing/Maximizing $f(x)$: We seek roots of $f'(x) = 0$, hence: $x_{k+1} = x_k - \frac{\mathbf{f'(x_k)}}{\mathbf{f''(x_k)}}$.
Remember: Optimization requires the ratio of the first derivative over the second derivative!

Week 05 Multivariate & Constrained Optimization

1. Core Concepts & Systematic Breakdown

Engineering and machine learning systems operate in multidimensional vector spaces $\mathbb{R}^n$. Multivariate optimization provides the analytical and numerical framework to navigate high-dimensional cost surfaces, find optimal parameter vectors, and satisfy real-world operational constraints.

A. Multivariate Differential Calculus: Gradient & Contours

For a scalar field $f(x): \mathbb{R}^n \to \mathbb{R}$, where $x = [x_1, x_2, \dots, x_n]^T$:

  • Gradient Vector $\nabla f(x)$: The vector of first-order partial derivatives: $$\nabla f(x) = \begin{bmatrix} \frac{\partial f}{\partial x_1} \ \frac{\partial f}{\partial x_2} \ \vdots \ \frac{\partial f}{\partial x_n} \end{bmatrix} \in \mathbb{R}^{n \times 1}$$
  • Four Fundamental Geometric Properties of the Gradient:
    • 1. $\mathbf{\nabla f(x)}$ points in the direction of the greatest (steepest) rate of increase of the function.
    • 2. $\mathbf{-\nabla f(x)}$ points in the direction of the greatest (steepest) rate of decrease of the function.
    • 3. The magnitude $\|\nabla f(x)\|$ represents the maximum directional derivative at that point.
    • 4. $\mathbf{\nabla f(x)}$ is ALWAYS orthogonal (perpendicular) to the contour curves / level sets $f(x) = c$. (Exam Trap: It is NEVER parallel to the contours!)

B. The Hessian Matrix, Sylvester's Criterion & Curvature Classification

The second-order curvature of $f(x)$ is captured by the Hessian matrix $\nabla^2 f(x) = H(x) \in \mathbb{R}^{n \times n}$: $$H(x) = \begin{bmatrix} \frac{\partial^2 f}{\partial x_1^2} & \frac{\partial^2 f}{\partial x_1 \partial x_2} & \dots & \frac{\partial^2 f}{\partial x_1 \partial x_n} \\ \frac{\partial^2 f}{\partial x_2 \partial x_1} & \frac{\partial^2 f}{\partial x_2^2} & \dots & \frac{\partial^2 f}{\partial x_2 \partial x_n} \\ \vdots & \vdots & \ddots & \vdots \\ \frac{\partial^2 f}{\partial x_n \partial x_1} & \frac{\partial^2 f}{\partial x_n \partial x_2} & \dots & \frac{\partial^2 f}{\partial x_n^2} \end{bmatrix}$$

  • Symmetry Theorem: By Schwarz's theorem on mixed partials, if second derivatives are continuous, $\frac{\partial^2 f}{\partial x_i \partial x_j} = \frac{\partial^2 f}{\partial x_j \partial x_i}$. Therefore, the Hessian matrix is ALWAYS symmetric ($H = H^T$)!
  • General Eigenvalue Classification at Stationary Point ($\nabla f(x^*) = 0$):
    • Strict Local Minimum: Positive Definite ($H \succ 0$) $\iff$ all eigenvalues $\lambda_i > 0$.
    • Strict Local Maximum: Negative Definite ($H \prec 0$) $\iff$ all eigenvalues $\lambda_i < 0$.
    • Saddle Point: Indefinite $\iff$ eigenvalues have mixed signs (at least one $\lambda_i > 0$ and one $\lambda_j < 0$).
    • Inconclusive: Semi-definite with $\lambda_i = 0$.
  • 2D Sylvester's Determinant Criterion (Crucial Shortcut): For a 2-variable function with Hessian $H = \begin{bmatrix} a & b \\ b & c \end{bmatrix} = \begin{bmatrix} f_{xx} & f_{xy} \\ f_{xy} & f_{yy} \end{bmatrix}$:
    • $\det(H) = ac - b^2 > 0$ and $a > 0 \implies$ Local Minimum.
    • $\det(H) = ac - b^2 > 0$ and $a < 0 \implies$ Local Maximum.
    • $\det(H) = ac - b^2 < 0 \implies$ Saddle Point (eigenvalues have opposite signs).
    • $\det(H) = ac - b^2 = 0 \implies$ Test is inconclusive.

C. Multidimensional Search Algorithms: Direction & Step Length

All gradient-based iterative optimization algorithms follow the general descent paradigm: $$x_{k+1} = x_k + \alpha_k d_k$$ where at every iteration $k$, the algorithm computes:

  • 1. Search Direction $d_k$: A vector in $\mathbb{R}^n$ along which the objective function decreases (descent direction satisfies $\nabla f(x_k)^T d_k < 0$).
    • In Steepest Descent: $d_k = -\nabla f(x_k)$.
    • In Newton's Method: $d_k = -[H(x_k)]^{-1} \nabla f(x_k)$.
  • 2. Step Length $\alpha_k > 0$: Determines how far to advance along direction $d_k$ (e.g. constant learning rate, exact line search $\alpha_k = \arg\min_\alpha f(x_k + \alpha d_k)$, or backtracking Armijo conditions).

D. Constrained Optimization: Direct Substitution vs Lagrange Multipliers

Consider minimizing $f(x_1, x_2)$ subject to an equality constraint $g(x_1, x_2) = 0$:

  • Direct Substitution Method: If $g(x_1, x_2) = 0$ can be solved explicitly for one variable (e.g., $x_2 = h(x_1)$), substitute directly into $f(x_1, h(x_1))$ to convert the problem into an unconstrained univariate optimization problem. Simple, but only feasible for algebraically invertible constraints.
  • Lagrange Multipliers (General Analytical Method): At a constrained optimum, the contour of $f(x)$ must be tangent to the constraint manifold $g(x) = 0$, requiring their gradients to be collinear: $$\nabla f(x) + \lambda \nabla g(x) = 0$$ Define the Lagrangian: $L(x, \lambda) = f(x) + \lambda g(x)$.
    Setting $\nabla_x L = 0$ and $\frac{\partial L}{\partial \lambda} = g(x) = 0$ yields a system of $n + 1$ equations in $n + 1$ unknowns.
  • Multi-Constraint Lagrangian: For $m$ equality constraints $g_i(x) = 0$ and $p$ inequality constraints $h_j(x) \le 0$: $$L(x, \lambda, \mu) = f(x) + \sum_{i=1}^m \lambda_i g_i(x) + \sum_{j=1}^p \mu_j h_j(x)$$

E. Karush–Kuhn–Tucker (KKT) Conditions for Inequalities

For $\min f(x)$ subject to inequality constraints $h_j(x) \le 0$ ($j = 1, \dots, p$):
The KKT Necessary Conditions at optimum $x^*$ require:

  • 1. Stationarity: $\nabla f(x^*) + \sum_{j=1}^p \mu_j \nabla h_j(x^*) = 0$
  • 2. Primal Feasibility: $h_j(x^*) \le 0$ for all $j$
  • 3. Dual Feasibility: $\mu_j \ge 0$ for all $j$ (non-negative multiplier for $\le$ inequality)
  • 4. Complementary Slackness: $\mu_j h_j(x^*) = 0$ for all $j$. (If constraint is inactive $h_j < 0$, then $\mu_j = 0$; if active $h_j = 0$, $\mu_j \ge 0$).
⚠️

NPTEL Exam Pitfall: Contour Alignment & Hessian Symmetry

Statement 1: "The gradient of a function at a point is parallel to the contours." $\implies$ FALSE! The gradient is strictly perpendicular (orthogonal) to contours.
Statement 2: "Hessian is a non-symmetric matrix." $\implies$ FALSE! For any twice continuously differentiable function, $H = H^T$ is always symmetric.
Statement 3: "The solution to an unconstrained optimization problem is always the same as the constrained one." $\implies$ FALSE! Constraints restrict the feasible domain, typically increasing the minimum cost.

Professor's 5-Step Lagrange Multiplier Blueprint

When solving $\min f(x_1, x_2)$ subject to $a x_1 + b x_2 = c$:
1. Set up Lagrangian: $L(x_1, x_2, \lambda) = f(x_1, x_2) + \lambda(a x_1 + b x_2 - c)$.
2. Differentiate w.r.t. $x_1$: $\frac{\partial L}{\partial x_1} = 0 \implies$ express $x_1$ in terms of $\lambda$.
3. Differentiate w.r.t. $x_2$: $\frac{\partial L}{\partial x_2} = 0 \implies$ express $x_2$ in terms of $\lambda$.
4. Substitute $x_1(\lambda)$ and $x_2(\lambda)$ into constraint $g(x_1, x_2) = 0$ to solve for scalar $\lambda^*$.
5. Back-substitute $\lambda^*$ to obtain $(x_1^*, x_2^*)$ and evaluate $f(x_1^*, x_2^*)$.

  2. Derive the first-order necessary conditions (FONC) with respect to $x$, $y$, and $\lambda$.
  3. Solve the resulting system of linear equations for the optimal coordinates $(x^*, y^*)$ and multiplier $\lambda^*$.

📘 View Comprehensive Step-by-Step Instructor Solution▼
Step 1: Formulate the Lagrangian

We want to maximize $f(x, y)$ subject to $g(x, y) = x + 3y - 10 = 0$: $$L(x, y, \lambda) = (49 - x^2 - y^2) - \lambda(x + 3y - 10)$$ (or equivalently $+ \lambda(x + 3y - 10)$ with opposite sign of $\lambda$).

Step 2: First-Order Necessary Conditions (FONC)

$$\frac{\partial L}{\partial x} = -2x - \lambda = 0 \implies x = -\frac{\lambda}{2}$$ $$\frac{\partial L}{\partial y} = -2y - 3\lambda = 0 \implies y = -\frac{3\lambda}{2}$$ $$\frac{\partial L}{\partial \lambda} = -(x + 3y - 10) = 0 \implies x + 3y = 10$$

$$f(1, 3) = 49 - (1)^2 - (3)^2 = 49 - 1 - 9 = \mathbf{39}$$

Week 06 Predictive Modeling: Linear Regression

NPTEL Lectures 29–38 | Ordinary Least Squares, Assumptions (LINE), Residuals, ANOVA Decomposition, R², and MLR

1. Core Concepts & Systematic Breakdown

Linear regression is the bedrock predictive supervised learning algorithm for quantitative continuous target variables. It formalizes an empirical relationship between one or more predictor (independent) variables and a scalar response (dependent) variable.

A. Simple Linear Regression (SLR) & OLS Formulation

The theoretical population model relating predictor $X$ to response $Y$ is: $$Y_i = \beta_0 + \beta_1 X_i + \epsilon_i, \quad i = 1, \dots, n$$ where $\beta_0$ is the intercept, $\beta_1$ is the regression slope, and $\epsilon_i$ represents unobserved random error.

  • The Gauss–Markov Assumptions (LINE):
    • L (Linearity): The relationship between $X$ and the conditional mean of $Y$ is linear: $E[Y \mid X] = \beta_0 + \beta_1 X$.
    • I (Independence): The error terms $\epsilon_i$ are mutually independent ($\text{Cov}(\epsilon_i, \epsilon_j) = 0$ for $i \ne j$).
    • N (Normality): Errors are normally distributed: $\epsilon_i \sim N(0, \sigma^2)$.
    • E (Equal Variance / Homoscedasticity): The variance of errors is constant across all predictor levels: $\text{Var}(\epsilon_i) = \sigma^2$.
  • Ordinary Least Squares (OLS) Derivation:
    OLS minimizes the sum of squared vertical residuals (Error Sum of Squares): $$\min_{\beta_0, \beta_1} \text{SSE}(\beta_0, \beta_1) = \sum_{i=1}^n (Y_i - \beta_0 - \beta_1 X_i)^2$$ Setting partial derivatives to zero yields the closed-form estimators: $$\mathbf{\hat{\beta}_1 = \frac{\sum_{i=1}^n (X_i - \bar{X})(Y_i - \bar{Y})}{\sum_{i=1}^n (X_i - \bar{X})^2} = \frac{\text{Cov}(X, Y)}{\text{Var}(X)} = r_{XY}\frac{s_Y}{s_X}}$$ $$\mathbf{\hat{\beta}_0 = \bar{Y} - \hat{\beta}_1 \bar{X}}$$ Crucial Property: The fitted regression line always passes through the centroid $(\bar{X}, \bar{Y})$!

B. Residuals & Geometric Properties

For observation $i$, the residual error is defined as: $$\mathbf{e_i = Y_i - \hat{Y}_i = Y_i - (\hat{\beta}_0 + \hat{\beta}_1 X_i)}$$ Exam Trap: Residual is strictly Actual minus Predicted ($Y - \hat{Y}$), NOT $\hat{Y} - Y$!

  • Sum of residuals is always zero: $\sum_{i=1}^n e_i = 0 \implies \bar{e} = 0$.
  • Residuals are strictly orthogonal to predictor values: $\sum_{i=1}^n e_i X_i = 0$.
  • Residuals are orthogonal to fitted values: $\sum_{i=1}^n e_i \hat{Y}_i = 0$.

C. Sum of Squares Decomposition & Shortcut Computational Formulas

The total variability in response $Y$ partitions cleanly into explained (regression) and unexplained (residual error) components: $$\mathbf{\text{SST} = \text{SSR} + \text{SSE}}$$

  • Total Sum of Squares (SST): $S_{YY} = \sum (Y_i - \bar{Y})^2 = \sum Y_i^2 - \frac{(\sum Y_i)^2}{n}$ with $\text{df} = n - 1$.
  • Regression Sum of Squares (SSR): $\sum (\hat{Y}_i - \bar{Y})^2 = \hat{\beta}_1 S_{XY} = \mathbf{\frac{S_{XY}^2}{S_{XX}}}$ with $\text{df} = p$ ($1$ for SLR).
  • Error / Residual Sum of Squares (SSE): $\sum (Y_i - \hat{Y}_i)^2 = \mathbf{\text{SST} - \text{SSR} = S_{YY} - \frac{S_{XY}^2}{S_{XX}}}$ with $\text{df} = n - p - 1$.
  • Mean Squared Errors: $\text{MSR} = \frac{\text{SSR}}{p}$ and $\text{MSE} = s_e^2 = \frac{\text{SSE}}{n - p - 1}$. Residual Standard Error is $s_e = \sqrt{\text{MSE}}$.
  • Coefficient of Determination ($R^2$): $$R^2 = \frac{\text{SSR}}{\text{SST}} = 1 - \frac{\text{SSE}}{\text{SST}} = \frac{S_{XY}^2}{S_{XX} S_{YY}} = r_{XY}^2 \in [0, 1]$$
  • Adjusted $R^2$: $$\text{Adjusted } R^2 = 1 - \left[\frac{\text{SSE}/(n - p - 1)}{\text{SST}/(n - 1)}\right] = 1 - (1 - R^2)\frac{n - 1}{n - p - 1}$$ Unlike $R^2$ which artificially increases with every added variable, Adjusted $R^2$ penalizes redundant predictors and only rises if the variable significantly improves explanatory power.

D. Line-by-Line Guide to R summary(lm()) Output

  • Residuals Summary (Min, 1Q, Median, 3Q, Max): Checks residual symmetry. Under normality, the median should be close to $0$, and $|\text{1Q}| \approx |\text{3Q}|$.
  • Coefficients Table:
    • Estimate: OLS estimates $\hat{\beta}_0$ (Intercept) and $\hat{\beta}_j$ (Slopes).
    • Std. Error: $\text{SE}(\hat{\beta}_j) = \sqrt{\text{MSE} \cdot (X^T X)^{-1}_{jj}}$.
    • t value: Test statistic $t = \frac{\hat{\beta}_j - 0}{\text{SE}(\hat{\beta}_j)}$ under null hypothesis $H_0: \beta_j = 0$.
    • Pr(>|t|): Two-tailed p-value. If $p < 0.05$, predictor is statistically significant.
  • Residual Standard Error ($s_e$): Estimate of population error standard deviation $\sigma = \sqrt{\text{MSE}}$ on $n - p - 1$ degrees of freedom.
  • F-Statistic: Tests global hypothesis $H_0: \beta_1 = \beta_2 = \dots = \beta_p = 0$ (all slopes zero simultaneously): $$F = \frac{\text{MSR}}{\text{MSE}} = \frac{\text{SSR}/p}{\text{SSE}/(n - p - 1)} \sim F_{p, \; n - p - 1}$$

E. Regression Diagnostics: The 4 Fundamental Residual Plots

  • 1. Residuals vs Fitted: Verifies linearity and homoscedasticity. Points should form an unstructured random horizontal cloud around zero. Any curved trend indicates non-linearity; a funnel/megaphone shape signals heteroscedasticity (non-constant variance).
  • 2. Normal Q-Q Plot: Evaluates normality of error distribution. Standardized residuals plotted against theoretical standard normal quantiles. Points must track the straight diagonal line. Severe S-curves indicate heavy tails or skewness.
  • 3. Scale-Location Plot: $\sqrt{|\text{Standardized Residuals}|}$ vs Fitted values. Assesses homoscedasticity. The red smoother line should remain roughly horizontal and flat.
  • 4. Residuals vs Leverage (Cook's Distance): Identifies influential observations that disproportionately pull the regression line.
    • Leverage $h_{ii}$ threshold: Points with $h_{ii} > \frac{2(p+1)}{n}$ have high leverage in predictor space.
    • Cook's Distance $D_i$: Measures overall change in fitted values when observation $i$ is removed. Observations with $D_i > 1$ (or $D_i > 4/n$) are dangerous influential outliers.

F. Multiple Regression, VIF & Confidence vs Prediction Intervals

  • Matrix MLR: $Y = X\beta + \epsilon \implies \hat{\beta} = (X^T X)^{-1} X^T Y$. Requires $X$ to have full column rank ($p+1$).
  • Variance Inflation Factor (VIF): Quantifies multicollinearity among predictors: $\text{VIF}_j = \frac{1}{1 - R_j^2}$. $\text{VIF} > 5$ or $10$ indicates severe correlation, inflating parameter standard errors.
  • Confidence Interval for Mean Response $E[Y \mid X_0]$: $$\hat{Y}_0 \pm t_{\alpha/2, n-2} \, s_e \sqrt{\frac{1}{n} + \frac{(X_0 - \bar{X})^2}{S_{XX}}}$$
  • Prediction Interval for a Single Individual $Y_{\text{new}}$: $$\hat{Y}_0 \pm t_{\alpha/2, n-2} \, s_e \sqrt{1 + \frac{1}{n} + \frac{(X_0 - \bar{X})^2}{S_{XX}}}$$
    • KEY EXAM COMPARISON: The Prediction Interval is ALWAYS strictly wider than the Confidence Interval because of the $+1$ variance term representing individual observation noise.
    • Both intervals are narrowest at the centroid $X_0 = \bar{X}$ and flare outwards parabolically as $X_0$ deviates from $\bar{X}$.
⚠️

NPTEL Exam Pitfall: Residual Error Sign & Covariance vs Correlation

Trap 1: Always compute $e = Y_{\text{actual}} - \hat{Y}_{\text{predicted}}$. If actual is $94.5$ and predicted is $83.9845$, residual error is $+10.5155$, NOT $-10.5155$!
Trap 2: "Covariance is a better metric than correlation to analyze association." $\implies$ FALSE! Covariance is scale-dependent (changes if you change units from meters to millimeters). Correlation is normalized to $[-1, 1]$, making it unitless and strictly comparable.

2. Essential Mathematical Formulas & ANOVA Identities

OLS Slope & Intercept Closed-Form
$$\hat{\beta}_1 = \frac{S_{XY}}{S_{XX}} = r\frac{s_Y}{s_X}, \quad \hat{\beta}_0 = \bar{Y} - \hat{\beta}_1 \bar{X}$$
Slope equals ratio of sample covariance to sample variance of predictor. Intercept forces line through centroid $(\bar{X}, \bar{Y})$.
Ex 1 Given $s_X = 4, s_Y = 10, r_{XY} = 0.8, \bar{X} = 15, \bar{Y} = 40$. Find the fitted line equation.
Sol: Slope $\hat{\beta}_1 = 0.8(10/4) = 2.0$. Intercept $\hat{\beta}_0 = 40 - (2.0)(15) = 10$. Fitted line: $\hat{Y} = 10 + 2X$.
Ex 2 Prove whether the centroid $(\bar{X}, \bar{Y})$ must satisfy the OLS regression line.
Sol: Yes. By definition $\hat{\beta}_0 = \bar{Y} - \hat{\beta}_1 \bar{X} \implies \hat{Y}(\bar{X}) = \bar{Y} - \hat{\beta}_1 \bar{X} + \hat{\beta}_1 \bar{X} = \bar{Y}$. Centroid always lies on the line.
ANOVA Identity & $R^2$ Variance
$$\text{SST} = \text{SSR} + \text{SSE}, \quad R^2 = \frac{\text{SSR}}{\text{SST}} = 1 - \frac{\text{SSE}}{\text{SST}}$$
Total Sum of Squares (SST) partitioned into Regression Sum of Squares (SSR) and Error / Residual Sum of Squares (SSE).
Ex 1 A regression model has $\text{SST} = 500$ and $\text{SSE} = 125$. Compute $\text{SSR}$ and $R^2$.
Sol: $\text{SSR} = \text{SST} - \text{SSE} = 500 - 125 = 375$. Coefficient of determination $R^2 = \frac{\text{SSR}}{\text{SST}} = \frac{375}{500} = 0.75$ (75% variance explained).
Ex 2 What is the relationship between ANOVA $R^2$ and Pearson correlation $r_{XY}$ in SLR?
Sol: In simple linear regression with an intercept, $R^2 = r_{XY}^2$. If $r_{XY} = -0.70$, then $R^2 = (-0.70)^2 = 0.49$.
Adjusted Coefficient of Determination Parsimony
$$\text{Adj } R^2 = 1 - (1 - R^2)\frac{n - 1}{n - p - 1} = 1 - \frac{\text{SSE}/(n - p - 1)}{\text{SST}/(n - 1)}$$
Penalizes model for degrees of freedom consumed by $p$ predictors. Guards against overfitting.
Ex 1 Given $n = 31, p = 2$ predictors, and $R^2 = 0.70$, calculate Adjusted $R^2$.
Sol: $\text{Adj } R^2 = 1 - (1 - 0.70)\frac{30}{31 - 2 - 1} = 1 - (0.30)\frac{30}{28} = 1 - 0.3214 = 0.6786$.
Ex 2 Can Adjusted $R^2$ decrease when an additional predictor is added?
Sol: Yes. While $R^2$ never decreases, Adjusted $R^2$ drops if the reduction in $\text{SSE}$ is insufficient to offset the loss of 1 error degree of freedom.
MLR Normal Equations Matrix OLS
$$\hat{\beta} = (X^T X)^{-1} X^T Y$$
Matrix OLS solution minimizing $\|Y - X\beta\|^2$, assuming design matrix $X$ has full column rank.
Ex 1 For $n = 50$ rows and $p = 4$ predictors, what is the dimension of $X$ and $(X^T X)^{-1}$?
Sol: Including intercept column of $1$s, $X$ is $50 \times 5$. The matrix $X^T X$ and its inverse $(X^T X)^{-1}$ are $(p+1) \times (p+1) = 5 \times 5$.
Ex 2 Under what condition does $(X^T X)^{-1}$ fail to exist?
Sol: When $X$ does not have full column rank ($\text{rank}(X) < p + 1$) due to perfect multicollinearity (one predictor is an exact linear combination of others).
Sum of Squares Shortcut Identities Computation
$$\text{SSR} = \frac{S_{XY}^2}{S_{XX}}, \quad \text{SSE} = S_{YY} - \frac{S_{XY}^2}{S_{XX}}, \quad \text{SST} = S_{YY}$$
Direct computation of ANOVA sum of squares using only bivariate summary cross-products $S_{XX}, S_{YY}, S_{XY}$.
Ex 1 If $S_{XX} = 50, S_{YY} = 200, S_{XY} = 80$, find $\text{SSR}$, $\text{SSE}$, and $R^2$.
Sol: $\text{SSR} = 80^2 / 50 = 6400 / 50 = 128$. $\text{SSE} = \text{SST} - \text{SSR} = 200 - 128 = 72$. $R^2 = 128 / 200 = 0.64$ (64%).
Ex 2 For $n = 10$, calculate the unbiased estimate of error variance $s_e^2$.
Sol: $s_e^2 = \text{MSE} = \text{SSE} / (n - 2) = 72 / (10 - 2) = 72 / 8 = 9.0$. Residual standard error is $s_e = 3.0$.
Mean vs Individual Response Intervals Inference
$$\text{SE}(\hat{\mu}_0) = s_e\sqrt{\frac{1}{n} + \frac{(X_0-\bar{X})^2}{S_{XX}}}, \quad \text{SE}(Y_{\text{new}}) = s_e\sqrt{1 + \frac{1}{n} + \frac{(X_0-\bar{X})^2}{S_{XX}}}$$
Prediction interval for a new observation is always wider than the confidence interval for the conditional mean due to $+1$ individual error variance.
Ex 1 At what predictor value $X_0$ is the confidence interval for mean response narrowest?
Sol: At the sample centroid $X_0 = \bar{X}$, where $(X_0 - \bar{X})^2 = 0$, giving minimum standard error $s_e / \sqrt{n}$.
Ex 2 Why is the prediction interval for $Y_{\text{new}}$ always wider than for $E[Y \mid X_0]$?
Sol: A single future observation involves two independent sources of variability: uncertainty in the estimated regression line PLUS the intrinsic random noise $\epsilon_i$ of individual data points.

Week 07 Classification, Cross-Validation & Logistic Regression

NPTEL Lectures 39–45 | Model Validation (LOOCV, k-Fold), Logistic Regression, Sigmoid, Odds, and Confusion Matrix

1. Core Concepts & Systematic Breakdown

When the response variable is qualitative (categorical) rather than continuous, linear regression breaks down mathematically. Week 7 introduces the rigorous foundations of classification, resampling validation techniques, and the logistic regression model.

A. Bias–Variance Decomposition & Cross-Validation Techniques

The expected test mean squared error of a predictive model decomposes into three non-negative components: $$\text{Expected Test MSE} = \text{Bias}^2(\hat{f}(x_0)) + \text{Var}(\hat{f}(x_0)) + \sigma^2$$ where $\sigma^2$ is irreducible error.

  • Crucial Conceptual Distinction: Bias–Variance Trade-off is a theoretical principle describing model flexibility vs error, NOT a cross-validation technique!
  • The Three Formal Cross-Validation Techniques:
    • 1. Validation Set Approach: Randomly divides data into a training set (e.g. 70%) and a validation/test set (30%). Limitations: High variability depending on the specific random split; overestimates test error because the model is trained on fewer observations.
    • 2. $k$-Fold Cross-Validation: Randomly divides data into $k$ equal-sized folds. For each fold $j \in \{1, \dots, k\}$, the model is trained on the remaining $k-1$ folds and tested on fold $j$. The cross-validation error is: $$\text{CV}_{(k)} = \frac{1}{k}\sum_{j=1}^k \text{MSE}_j$$ Typically $k = 5$ or $k = 10$. Provides an optimal balance between computational tractability, bias, and variance.
    • 3. Leave-One-Out Cross-Validation (LOOCV): The extreme case where $k = n$ (sample size). Exactly one observation is left out for testing, while $n-1$ are used for training. Repeated $n$ times.
      • Advantages: Completely deterministic (zero randomness in splitting); almost unbiased estimate of test error.
      • Disadvantages: Computationally expensive ($n$ model fits); high variance among test error estimates due to highly correlated training sets.

B. Classification vs Regression: Why Ordinary Linear Regression Fails

A classification problem predicts a qualitative categorical label $Y \in \{0, 1\}$ or $\{1, \dots, C\}$ (e.g. Patient Diagnosed with Disease: Yes/No; Rain Tomorrow: Yes/No).
Ordinary linear regression fails for classification because:

  • 1. Unbounded Predictions: Linear regression $\hat{Y} = X\beta$ produces values outside $[0, 1]$ ($< 0$ or $> 1$), violating the axioms of probability.
  • 2. Heteroscedasticity: The error variance $\text{Var}(Y \mid X) = p(X)(1 - p(X))$ changes with $X$, violating the constant variance assumption.
  • 3. Non-Normality of Residuals: Errors take on only two discrete values ($1 - p(X)$ or $-p(X)$), violating Gaussian error assumptions.
  • 4. Arbitrary Metric Encoding: Assigning dummy numbers like $1, 2, 3$ to unordered categories creates artificial ordinal distances that bias the model.

C. The Logistic Regression Model: Sigmoid, Odds, and Logit

Logistic regression directly models the conditional probability $p(X) = P(Y = 1 \mid X)$:

  • The Sigmoid / Logistic Function: $$\mathbf{p(X) = \frac{e^{\beta_0 + \beta_1 X}}{1 + e^{\beta_0 + \beta_1 X}} = \frac{1}{1 + e^{-(\beta_0 + \beta_1 X)}} \in (0, 1)}$$ S-shaped curve strictly bounded between 0 and 1.
  • Odds: The ratio of success probability to failure probability: $$\mathbf{\text{Odds} = \frac{p(X)}{1 - p(X)} = e^{\beta_0 + \beta_1 X} \in (0, \infty)}$$
  • Log-Odds (Logit Transformation): $$\mathbf{\ln\left(\frac{p(X)}{1 - p(X)}\right) = \beta_0 + \beta_1 X \in (-\infty, \infty)}$$ The logit transformation linearizes the logistic relationship! A 1-unit increase in $X$ changes the log-odds by $\beta_1$, and multiplies the odds by the factor $e^{\beta_1}$ (Odds Ratio).
  • Maximum Likelihood Estimation (MLE): Logistic regression coefficients are fitted not via least squares, but by maximizing the Bernoulli joint likelihood function: $$L(\beta) = \prod_{i=1}^n [p(x_i)]^{y_i} [1 - p(x_i)]^{1 - y_i}$$

D. Classification Performance Assessment (Confusion Matrix)

Evaluating binary predictions against ground truth using a $2 \times 2$ Confusion Matrix:

Predicted: Positive ($\hat{Y} = 1$) Predicted: Negative ($\hat{Y} = 0$) Total
Actual: Positive ($Y = 1$) True Positive (TP) False Negative (FN) [Type II] Actual Positives ($TP + FN$)
Actual: Negative ($Y = 0$) False Positive (FP) [Type I] True Negative (TN) Actual Negatives ($TN + FP$)
  • Accuracy: $\frac{TP + TN}{TP + TN + FP + FN} = \frac{\text{Correct Predictions}}{\text{Total Population}}$.
    • Error Rate: $1 - \text{Accuracy} = \frac{FP + FN}{TP + TN + FP + FN}$.
  • Sensitivity (Recall / True Positive Rate - TPR): $$\mathbf{\text{Sensitivity} = \frac{TP}{TP + FN}}$$ Proportion of actual positive cases correctly identified. Crucial in disease diagnosis!
  • Specificity (True Negative Rate - TNR): $$\mathbf{\text{Specificity} = \frac{TN}{TN + FP}}$$ Proportion of actual negative cases correctly cleared.
  • False Positive Rate (FPR): $\text{FPR} = 1 - \text{Specificity} = \frac{FP}{TN + FP}$ (type I error rate; false alarms).
  • False Negative Rate (FNR): $\text{FNR} = 1 - \text{Sensitivity} = \frac{FN}{TP + FN}$ (type II error rate; missed detections).
  • Precision (Positive Predictive Value - PPV): $$\mathbf{\text{Precision} = \frac{TP}{TP + FP}}$$ Proportion of positive alarms that are truly positive.
  • Negative Predictive Value (NPV): $\text{NPV} = \frac{TN}{TN + FN}$.
  • $F_1$-Score: Harmonic mean of Precision and Recall: $$F_1 = 2 \cdot \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}} = \frac{2TP}{2TP + FP + FN} \in [0, 1]$$ Preferred over accuracy on heavily imbalanced datasets (e.g., fraud detection where negatives are $99.9\%$).
  • ROC Curve & AUC: Receiver Operating Characteristic curve plots $\text{Sensitivity}$ ($y$-axis) vs $1 - \text{Specificity}$ ($x$-axis) across all possible probability classification thresholds $p^* \in [0, 1]$. Area Under the Curve (AUC) ranges from $0.5$ (random guess) to $1.0$ (perfect discrimination).
⚠️

NPTEL Exam Pitfall: glm() Family & predict() type Parameter

Trap 1: In R's glm(), the argument family = binomial (or family = "binomial") is mandatory for logistic regression. If omitted, R fits a standard linear model (family = gaussian)!
Trap 2: To obtain predicted probabilities $P(Y=1|X) \in [0, 1]$, you must write predict(model, type = "response"). Omitting type = "response" returns the linear log-odds (link scale: $\beta_0 + \beta_1 X$) which can be negative or greater than 1!

🎯

Professor's Confusion Matrix Denominator Rule

Never mix up metric denominators:
• Sensitivity (Recall): Divisor is Actual Positives ($TP + FN$).
• Specificity: Divisor is Actual Negatives ($TN + FP$).
• Precision: Divisor is Predicted Positives ($TP + FP$).
• Accuracy: Divisor is Total Population ($TP + TN + FP + FN$).

2. Essential Mathematical Formulas & Classification Metrics

Sigmoid / Logistic Function Probability
$$p(X) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 X)}}$$
Maps any real-valued linear input $(-\infty, \infty)$ strictly into valid probability range $(0, 1)$.
Ex 1 If logit $z = \beta_0 + \beta_1 X = -1.5 + 0.5(5) = 1.0$, find predicted probability $p$.
Sol: $p = \frac{1}{1 + e^{-1.0}} = \frac{1}{1 + 0.3679} = \frac{1}{1.3679} \approx 0.7311$ (73.11% probability).
Ex 2 For what value of linear predictor $z$ is the predicted probability exactly $0.50$?
Sol: $\frac{1}{1 + e^{-z}} = 0.5 \implies e^{-z} = 1 \implies z = 0$. Decision boundary cutoff occurs where $\beta_0 + \beta_1 X = 0 \implies X^* = -\beta_0 / \beta_1$.
Odds & Logit Transform Log-Odds
$$\text{Odds} = \frac{p}{1-p}, \quad \text{logit}(p) = \ln\left(\frac{p}{1-p}\right) = \beta_0 + \beta_1 X$$
Logit linearizes parameter estimation. Odds ratio $e^{\beta_1}$ gives multiplicative odds increase per unit predictor change.
Ex 1 If an event has probability $p = 0.80$, compute its odds and logit.
Sol: $\text{Odds} = \frac{0.80}{1 - 0.80} = \frac{0.80}{0.20} = 4.0$ (4 to 1). $\text{logit}(0.80) = \ln(4.0) \approx 1.3863$.
Ex 2 If logistic slope $\hat{\beta}_1 = 0.693$, what is the odds ratio per unit increase in $X$?
Sol: $\text{Odds Ratio} = e^{\hat{\beta}_1} = e^{0.693} \approx 2.00$. Each 1-unit increase in $X$ doubles the odds of the target outcome.
Sensitivity (True Positive Rate) Recall
$$\text{TPR} = \frac{TP}{TP + FN}$$
Ability of model to detect actual positives without missing true diseased/target cases.
Ex 1 A test on 100 sick patients identifies 85 correctly ($TP = 85$) and misses 15 ($FN = 15$). Find Sensitivity.
Sol: $\text{Sensitivity} = \frac{85}{85 + 15} = \frac{85}{100} = 0.85$ (85% recall).
Ex 2 If a naive classifier predicts ALL cases as Positive, what are its Sensitivity and Specificity?
Sol: With $FN = 0$, $\text{Sensitivity} = \frac{TP}{TP + 0} = 1.00$ (100%). But $TN = 0$, so $\text{Specificity} = 0$, giving $\text{FPR} = 1 - 0 = 1.00$ (100% false alarms).
Specificity (True Negative Rate) Selectivity
$$\text{TNR} = \frac{TN}{TN + FP}$$
Ability of model to correctly clear non-target/healthy cases. False Positive Rate is $1 - \text{Specificity}$.
Ex 1 Out of 200 healthy patients, 180 test negative ($TN = 180$) and 20 test positive ($FP = 20$). Compute Specificity and FPR.
Sol: $\text{Specificity} = \frac{180}{180 + 20} = 0.90$ (90%). False Positive Rate $= 1 - \text{Specificity} = 1 - 0.90 = 0.10$ (10%).
Ex 2 What are the axes of a Receiver Operating Characteristic (ROC) curve?
Sol: The vertical $y$-axis is Sensitivity (True Positive Rate: $\frac{TP}{TP + FN}$), and the horizontal $x$-axis is $1 - \text{Specificity}$ (False Positive Rate: $\frac{FP}{TN + FP}$).
$k$-Fold Cross-Validation Error Resampling
$$\text{CV}_{(k)} = \frac{1}{k}\sum_{j=1}^k \text{MSE}_j$$
Averages validation errors across $k$ non-overlapping folds. Provides an almost unbiased estimate of out-of-sample test error.
Ex 1 In a 5-fold CV, MSEs on the 5 validation folds are $12, 16, 14, 18, 15$. Find $\text{CV}_{(5)}$.
Sol: $\text{CV}_{(5)} = \frac{12 + 16 + 14 + 18 + 15}{5} = \frac{75}{5} = 15.0$.
Ex 2 Why is $k$-fold cross-validation superior to a single validation split?
Sol: Every sample observation is used for testing exactly once. It avoids high dependency on an arbitrary single split and uses $(k-1)/k$ of the data for training.
$F_1$-Score (Harmonic Mean) Imbalanced Data
$$F_1 = 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}} = \frac{2TP}{2TP + FP + FN}$$
Harmonic mean balances Precision and Recall, heavily penalizing models that ignore either metric on skewed distributions.
Ex 1 A classifier has $\text{Precision} = 0.80$ and $\text{Recall} = 0.60$. Calculate $F_1$.
Sol: $F_1 = 2 \cdot \frac{0.80 \times 0.60}{0.80 + 0.60} = \frac{0.96}{1.40} \approx 0.6857$. (Harmonic mean is pulled toward the lower metric).
Ex 2 If $TP = 40, FP = 10, FN = 10, TN = 140$, find the $F_1$-score.
Sol: $F_1 = \frac{2(40)}{2(40) + 10 + 10} = \frac{80}{100} = 0.80$.

1. Core Concepts & Systematic Breakdown

The final module synthesizes machine learning paradigms by contrasting supervised instance-based learning ($K$-Nearest Neighbors) with unsupervised clustering ($K$-Means). Both algorithms rely fundamentally on geometric distance metrics in multidimensional feature space.

A. Supervised vs Unsupervised Learning Paradigms

  • Supervised Learning: Every training instance possesses an input feature vector $X_i$ paired with an explicit ground-truth supervisor label $Y_i$. Objective: learn mapping $f: X \to Y$.
    • Continuous $Y \implies$ Regression (Linear Regression, KNN Regressor).
    • Categorical $Y \implies$ Classification (Logistic Regression, KNN Classifier).
  • Unsupervised Learning: Data consists solely of input features $X_i$ with no target labels $Y$. Objective: discover latent groupings, natural cluster boundaries, or compact manifold representations ($K$-Means, Hierarchical Clustering, PCA).

B. K-Nearest Neighbors (KNN) Algorithm

KNN is a non-parametric, memory-based "lazy learner" that does not construct an explicit mathematical model during training. It simply memorizes the training data:

  • Algorithm Procedure: For an unlabelled query point $x_0$:
    1. Calculate distance from $x_0$ to all $n$ training instances using an appropriate metric:
    • Euclidean Distance ($L_2$): $d(x_0, x_i) = \sqrt{\sum_{j=1}^p (x_{0,j} - x_{i,j})^2}$
    • Manhattan Distance ($L_1$): $d(x_0, x_i) = \sum_{j=1}^p |x_{0,j} - x_{i,j}|$
    • Chebyshev Distance ($L_\infty$): $d(x_0, x_i) = \max_{1 \le j \le p} |x_{0,j} - x_{i,j}|$
    • Minkowski Distance ($L_q$): $d(x_0, x_i) = \left(\sum_{j=1}^p |x_{0,j} - x_{i,j}|^q\right)^{1/q}$
    2. Identify the set $\mathcal{N}_K(x_0)$ of the $K$ closest training points.
    3. Classification: Assign $x_0$ to the majority class via voting: $\hat{Y} = \operatorname{mode}(\{y_i \mid i \in \mathcal{N}_K\})$.
    4. Regression: Predict the average response: $\hat{Y} = \frac{1}{K}\sum_{i \in \mathcal{N}_K} y_i$ (or distance-weighted average).
  • Choice of Hyperparameter $K$ & Bias–Variance Tradeoff:
    • Odd $K$: Choosing an odd $K$ (e.g. $3, 5, 7$) is standard for binary classification to unconditionally prevent ties in majority voting.
    • Small $K$ ($K = 1$): Highly flexible boundary, zero training error, sensitive to noise/outliers $\implies$ High Variance, Low Bias (Overfitting).
    • Large $K$ ($K \to n$): Rigid, smooth boundary, highly stable against noise, but predicts global training class proportion $\implies$ Low Variance, High Bias (Underfitting).
    • Tuning: Optimal $K$ is selected via cross-validation.
  • Essential Properties of KNN:
    • KNN works for BOTH binary AND multi-class classification as well as continuous regression!
    • Feature Scaling is Mandatory: Unscaled variables with large ranges overwhelm distance metrics. Always preprocess features with scale().

C. K-Means Clustering: Lloyd's Algorithm & Objective Function

$K$-Means partitions $n$ observations into $K$ non-overlapping clusters $C_1, C_2, \dots, C_K$ such that each observation belongs to the cluster with the nearest centroid.

  • Mathematical Objective: Minimize the total Within-Cluster Sum of Squares (WSS): $$\min_{C_1, \dots, C_K} \sum_{k=1}^K \text{WSS}_k = \sum_{k=1}^K \sum_{x_i \in C_k} \|x_i - \mu_k\|^2$$ where $\mu_k = \frac{1}{|C_k|}\sum_{x_i \in C_k} x_i$ is the mean vector (centroid) of cluster $C_k$.
  • Lloyd's Iterative Protocol:
    1. Choose number of clusters $K$.
    2. Randomly initialize $K$ cluster centroids $\mu_1, \dots, \mu_K$.
    3. Assignment Step: Assign each data point to its nearest centroid based on Euclidean distance: $$c_i = \arg\min_{1 \le k \le K} \|x_i - \mu_k\|^2$$
    4. Update Step: Recompute each centroid as the arithmetic mean of all assigned points: $$\mu_k = \frac{1}{|C_k|}\sum_{x_i \in C_k} x_i$$
    5. Repeat steps 3 and 4 until cluster assignments stabilize (convergence).

D. Sum of Squares Decomposition in K-Means

Similar to regression ANOVA, the dispersion in clustering decomposes into: $$\mathbf{\text{Total Sum of Squares (TSS)} = \text{Between-Cluster SS (BCSS)} + \text{Within-Cluster SS (WSS)}}$$

  • Total Sum of Squares (TSS): Total dispersion of all $n$ points around the global grand mean $\bar{x}$: $$\text{TSS} = \sum_{i=1}^n \|x_i - \bar{x}\|^2$$ Professor's Scaled TSS Shortcut: If features are normalized using scale(), each feature has sample variance $= 1$. For $n$ observations and $p$ features: $$\mathbf{\text{TSS} = (n - 1) \times p}$$ For the standard USArrests dataset ($n = 50, p = 4$), $\text{TSS} = (50 - 1) \times 4 = \mathbf{196}$!
  • Within-Cluster Sum of Squares (WSS): Compactness of clusters: $$\text{WSS} = \sum_{k=1}^K \sum_{x_i \in C_k} \|x_i - \mu_k\|^2$$
  • Between-Cluster Sum of Squares (BCSS): Separation between cluster centroids: $$\text{BCSS} = \sum_{k=1}^K |C_k| \|\mu_k - \bar{x}\|^2 = \text{TSS} - \text{WSS}$$
  • A superior clustering solution maximizes the ratio $\frac{\text{BCSS}}{\text{TSS}} \to 100\%$.

E. Selecting Optimal $K$ & Local Minima

  • Elbow Method (Scree Plot): Plot total WSS against $K$. The curve drops rapidly initially and then flattens. The "elbow" indicates the point of diminishing returns, representing the optimal $K$.
  • Dendrogram: Tree diagram produced by Hierarchical Clustering to determine cluster count by cutting branches.
  • Why Scatter Plot is NOT Useful: A 2D scatter plot cannot handle multidimensional data ($p > 2$), nor does it provide a mathematical variance criterion to select $K$.
  • Sensitivity to Initial Centroids & nstart: $K$-Means converges to a local minimum. To find the true optimal partition, R provides the nstart parameter (e.g. nstart = 20), which runs 20 separate random initializations and retains the model with the minimum total WSS.

2. Essential Mathematical Formulas & Clustering Metrics

K-Means Objective (WSS) Compactness
$$\text{WSS} = \sum_{k=1}^K \sum_{x_i \in C_k} \|x_i - \mu_k\|^2$$
Sum of squared Euclidean distances of each point from its assigned cluster centroid. Lloyd's algorithm minimizes this function.
Ex 1 Points $(1, 2)$ and $(3, 4)$ form cluster $k$. Find centroid $\mu_k$ and $\text{WSS}_k$.
Sol: Centroid $\mu_k = (2, 3)$. Squared distances: $\|(1,2)-(2,3)\|^2 = 1+1 = 2$; $\|(3,4)-(2,3)\|^2 = 1+1 = 2$. Thus $\text{WSS}_k = 2 + 2 = 4$.
Ex 2 What is $\text{WSS}$ when $K = n$ (number of clusters equals sample size)?
Sol: Every point is its own centroid ($x_i = \mu_i$), so $\text{WSS} = 0$. The elbow method selects the point where marginal reduction in $\text{WSS}$ drops off sharply.
Clustering Conservation Law Decomposition
$$\text{TSS} = \text{BCSS} + \text{WSS}$$
Total sum of squares equals between-cluster dispersion plus within-cluster dispersion.
Ex 1 If a 3-cluster clustering yields $\text{TSS} = 200$ and total $\text{WSS} = 50$, compute $\text{BCSS}$ and explained variance ratio.
Sol: $\text{BCSS} = \text{TSS} - \text{WSS} = 200 - 50 = 150$. Ratio $\frac{\text{BCSS}}{\text{TSS}} = \frac{150}{200} = 0.75$ (75% of total variance explained by cluster separation).
Ex 2 In R's kmeans(), how is clustering quality evaluated?
Sol: Higher ratio betweenss / totss closer to $100\%$ indicates well-separated, compact clusters.
Scaled TSS Formula Standardization
$$\text{TSS}_{\text{scaled}} = (n - 1) \times p$$
For standardized data ($z$-scores), each feature has unit variance $s^2 = 1$. Total SS is exactly $(n-1)p$.
Ex 1 Standardized dataset USArrests has $n = 50$ states and $p = 4$ variables. Find $\text{TSS}$.
Sol: $\text{TSS} = (n - 1) \times p = (50 - 1) \times 4 = 49 \times 4 = 196$.
Ex 2 Why is standardization via scale() essential before K-means?
Sol: Prevents variables with arbitrarily large numerical scales (e.g., income in thousands vs. age in years) from dominating Euclidean distance calculations.
Euclidean Distance ($L_2$) Distance
$$d(x_i, x_j) = \sqrt{\sum_{r=1}^p (x_{ir} - x_{jr})^2}$$
Standard distance metric governing cluster assignment in K-means and neighborhood voting in KNN.
Ex 1 Find distance between query $q = (2, 3)$ and points $a = (5, 7)$ and $b = (1, 1)$. Which is closer?
Sol: $d(q, a) = \sqrt{(2-5)^2 + (3-7)^2} = \sqrt{9+16} = 5.0$. $d(q, b) = \sqrt{(2-1)^2 + (3-1)^2} = \sqrt{1+4} = \sqrt{5} \approx 2.236$. Point $b$ is the 1-NN.
Ex 2 If $K=3$ nearest neighbors have class labels $\{A, B, A\}$, what does KNN predict?
Sol: Majority vote gives Class $A$ with posterior probability $P(Y=A \mid x) = 2/3 \approx 66.7\%$.
Manhattan ($L_1$) & Chebyshev ($L_\infty$) Distance Metrics
$$d_1(u, v) = \sum_{r=1}^p |u_r - v_r|, \quad d_\infty(u, v) = \max_{1 \le r \le p} |u_r - v_r|$$
Alternative geometric distances. For all vector pairs in $\mathbb{R}^p$, the strict norm ordering $d_\infty \le d_2 \le d_1$ holds.
Ex 1 Compute $L_1$ and $L_\infty$ distances between $u = (1, 4)$ and $v = (5, 1)$.
Sol: Absolute differences are $|1-5| = 4$ and $|4-1| = 3$. Manhattan $d_1 = 4 + 3 = 7.0$. Chebyshev $d_\infty = \max(4, 3) = 4.0$. (Euclidean is $5.0$).
Ex 2 How do $L_1, L_2, L_\infty$ compare in magnitude?
Sol: Always $d_\infty(u, v) \le d_2(u, v) \le d_1(u, v)$. In the example: $4.0 \le 5.0 \le 7.0$.
Between-Cluster SS (BCSS) Separation
$$\text{BCSS} = \sum_{k=1}^K |C_k| \|\mu_k - \bar{x}\|^2 = \text{TSS} - \text{WSS}$$
Measures between-cluster separation (dispersion of cluster centroids around global grand mean). Maximizing BCSS/TSS yields optimal clusters.
Ex 1 $10$ points partition into 2 clusters around grand mean $\bar{x} = 0$: $n_1 = 6, \mu_1 = 2$; $n_2 = 4, \mu_2 = -3$. Compute $\text{BCSS}$.
Sol: $\text{BCSS} = 6(2 - 0)^2 + 4(-3 - 0)^2 = 6(4) + 4(9) = 24 + 36 = 60.0$.
Ex 2 If $\text{TSS} = 100$ and $\text{BCSS} = 60$, calculate $\text{WSS}$ and variance explained.

🎯 NPTEL MCQ (Single Correct) Question 9 • [2 Marks]
Topic: 2D Hessian Sylvester Criterion

Consider the multivariable function $f(x_1, x_2) = x_1^3 + x_2^3 - 3x_1 x_2$. The point $(x_1, x_2) = (1, 1)$ is a stationary point because $\nabla f(1, 1) = [0, 0]^T$. By computing the Hessian matrix $H(1, 1)$ and applying Sylvester's criterion, what is the nature of this stationary point?

  • (A) Local Minimum
  • (B) Local Maximum
  • (C) Saddle Point
  • (D) Inconclusive Test
💡 View Step-by-Step Solution & Distractor Analysis▼
Step 1: Second Partial Derivatives

• $\frac{\partial f}{\partial x_1} = 3x_1^2 - 3x_2 \implies \frac{\partial^2 f}{\partial x_1^2} = 6x_1$
• $\frac{\partial f}{\partial x_2} = 3x_2^2 - 3x_1 \implies \frac{\partial^2 f}{\partial x_2^2} = 6x_2$
• $\frac{\partial^2 f}{\partial x_1 \partial x_2} = -3$

Step 2: Construct Hessian at $(1, 1)$

$$H(1, 1) = \begin{bmatrix} 6(1) & -3 \\ -3 & 6(1) \end{bmatrix} = \begin{bmatrix} 6 & -3 \\ -3 & 6 \end{bmatrix}$$

Step 3: Apply Sylvester's Determinant Test

• First principal minor: $M_1 = 6 > 0$
• Second principal minor (determinant): $\det(H) = (6)(6) - (-3)(-3) = 36 - 9 = 27 > 0$
Since $M_1 > 0$ and $\det(H) > 0$, the Hessian is strictly positive definite ($H \succ 0$). Therefore, $(1, 1)$ is a strict local minimum.

✅ Correct Answer: (A) Local Minimum

⚠️ The 12 Most Lethal NPTEL Exam Traps & How to Evade Them

1

ls() vs dir()

ls() displays objects in the active R session RAM. It does NOT list files on disk! Use list.files() or dir() for disk files.

2

Negative Slicing A[-2, ]

In R, negative indices mean drop/exclude! A[-2, ] deletes row 2; it does NOT select the 2nd row from the bottom.

3

Variance of Difference

For independent variables: $\text{Var}(aX - bY) = a^2\text{Var}(X) \mathbf{+} b^2\text{Var}(Y)$. The minus sign squares to positive! Variances always add.

4

Gradient vs Contours

The gradient $\nabla f$ is strictly orthogonal / perpendicular to contour lines, NEVER parallel!

5

Hessian Symmetry

By Schwarz's theorem, mixed partials commute ($\frac{\partial^2 f}{\partial x_i \partial x_j} = \frac{\partial^2 f}{\partial x_j \partial x_i}$). Hence Hessian $H$ is ALWAYS symmetric ($H = H^T$).

6

Residual Error Sign

Residual error is defined as $e = Y_{\text{actual}} - \hat{Y}_{\text{predicted}}$. Never compute Predicted minus Actual!

7

Bias-Variance is NOT a CV Technique

LOOCV, $k$-fold, and validation sets are cross-validation methods. Bias-variance trade-off is an algorithm property, not a validation technique!

8

glm() Requires family = binomial

Fitting logistic regression requires family = binomial. Without it, R fits ordinary linear regression!

9

predict() type = "response"

To obtain probabilities $p \in [0, 1]$, you MUST pass type = "response". Default output is the unconstrained logit $\beta_0 + \beta_1 X$.

10

KNN is NOT Binary-Only

KNN works effortlessly for multi-class classification and continuous regression problems!

11

Central Tendency for Categorical Data

Mode is the ONLY central tendency measure applicable to nominal / categorical data. Mean and median are mathematically undefined for qualitative categories.

12

Prediction vs Confidence Interval

A Prediction Interval for a single new observation $Y_{\text{new}}$ is ALWAYS strictly wider than the Confidence Interval for the mean response $E[Y|X_0]$ due to the extra individual variance $+1$.
